# Network & API

**Network & API** - это раздел о том, как браузер общается с внешним миром. Здесь разбираем протоколы, запросы, кэширование, аутентификацию и паттерны работы с данными - всё, что стоит между `fetch()` и пикселями на экране.

---

## Зачем это нужно

- Вопрос «что происходит, когда ты вводишь URL?» - один из самых частых на интервью.
- CORS-ошибки - ежедневная боль фронтенд-разработчика. Без понимания SOP невозможно их чинить осознанно.
- Разница между HTTP/1.1, HTTP/2 и HTTP/3 влияет на стратегию загрузки ресурсов.
- Знание кэширования, аутентификации и real-time - то, что отличает уверенного разработчика от начинающего.

---

## Что здесь есть

- Основы сетей: TCP/IP, DNS, TLS, CDN - ровно столько, чтобы понимать контекст.
- HTTP: методы, статус-коды, заголовки, версии протокола.
- Жизненный цикл запроса: полный путь от URL до ответа.
- CORS и Same-Origin Policy: механика, preflight, типичные ошибки.
- REST и GraphQL: принципы, сравнение, когда что выбирать.
- Получение данных: fetch, AbortController, error handling, retry.
- Кэширование: HTTP-кэш, CDN, browser cache, application-level.
- Аутентификация: cookies, JWT, OAuth 2.0, хранение токенов.
- Браузерное хранилище: cookies, localStorage, IndexedDB, Cache API.
- Real-time: WebSockets, SSE, polling.
- Паттерны работы с API: версионирование, пагинация, optimistic updates.
