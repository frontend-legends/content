# Матрицы

Матрица — двумерный массив: строки и столбцы, клетки с координатами `(r, c)`. Задачи на матрицы проверяют аккуратность больше, чем знание алгоритмов: границы, направления, изменение на месте без копии и порядок обхода. Спрашивают валидацию судоку, обход по спирали, поворот изображения на 90° и задачи, где новое состояние зависит от старого, — «Жизнь» Конвея и обнуление строк и столбцов.

::tldr
- **Клетка — пара `(r, c)`, соседи — сдвиги из массива направлений.** Проверка границ в одном месте избавляет от половины ошибок.
- **Номер квадрата 3 × 3 в судоку — `Math.floor(r / 3) * 3 + Math.floor(c / 3)`:** так строки, столбцы и квадраты проверяются за один проход.
- **Поворот на 90° по часовой — транспонирование и разворот строк.** Работает на месте, без второй матрицы.
- **Если новое состояние зависит от старого, нельзя перезаписывать клетки сразу.** Либо копия, либо кодирование двух состояний в одной клетке, либо флаги в первой строке и столбце.
- **Обход по спирали — четыре границы, которые сжимаются после каждой стороны;** главная ловушка — повторный проход по последней строке или столбцу.
::

---

## Как узнать паттерн

Матричные задачи узнаются сразу по входным данным — двумерный массив. Дальше важно понять, какой тип задачи:

- **обход в особом порядке** — спираль, диагонали, зигзаг: моделируем движение с границами;
- **преобразование на месте** — поворот, отражение, транспонирование: раскладываем на простые отражения;
- **новое состояние из старого** — «Жизнь», обнуление строк: нужна копия или хитрое хранение двух состояний;
- **связные области** — острова, заливка: это уже граф, где клетки — вершины ([Графы](/content/algorithms-data-structures/graph-general));
- **поиск в отсортированной матрице** — двоичный поиск по развёрнутому массиву ([Двоичный поиск](/content/algorithms-data-structures/binary-search)).

## Шаблон

Соседей клетки перебирают по массиву направлений, а выход за границы проверяют в одном месте:

```ts
const DIRS = [[-1, 0], [1, 0], [0, -1], [0, 1]];         // вверх, вниз, влево, вправо

function neighbors(grid: number[][], r: number, c: number): [number, number][] {
  const out: [number, number][] = [];
  for (const [dr, dc] of DIRS) {
    const nr = r + dr;
    const nc = c + dc;
    if (nr >= 0 && nr < grid.length && nc >= 0 && nc < grid[0].length) out.push([nr, nc]);
  }
  return out;
}
```

Для восьми соседей — двойной цикл по `dr` и `dc` от −1 до 1 без `(0, 0)`. Обход всей матрицы — O(m · n), и это нижняя граница для большинства задач: каждую клетку надо хотя бы прочитать.

Помни, как матрица лежит в памяти: строка за строкой. Обход по строкам быстрее обхода по столбцам из-за кеша процессора ([Архитектура компьютера](/content/computer-science/computer-architecture)).

::practice{title="36. Valid Sudoku"}
Дана доска 9 × 9, частично заполненная цифрами, пустые клетки — `'.'`. Проверить, что в каждой строке, каждом столбце и каждом квадрате 3 × 3 нет повторяющихся цифр. Решаемость доски проверять не нужно. [Задача на LeetCode](https://leetcode.com/problems/valid-sudoku/)

#solution
Один проход и 27 множеств: по одному на строку, столбец и квадрат. Номер квадрата вычисляется из координат:

```ts
function isValidSudoku(board: string[][]): boolean {
  const rows = Array.from({ length: 9 }, () => new Set<string>());
  const cols = Array.from({ length: 9 }, () => new Set<string>());
  const boxes = Array.from({ length: 9 }, () => new Set<string>());
  for (let r = 0; r < 9; r++) {
    for (let c = 0; c < 9; c++) {
      const v = board[r][c];
      if (v === '.') continue;
      const b = Math.floor(r / 3) * 3 + Math.floor(c / 3);   // номер квадрата 3 × 3
      if (rows[r].has(v) || cols[c].has(v) || boxes[b].has(v)) return false;
      rows[r].add(v);
      cols[c].add(v);
      boxes[b].add(v);
    }
  }
  return true;
}
```

Размер доски фиксирован, поэтому формально O(1). Ошибки: неверная формула квадрата (`r / 3` без `Math.floor` даёт дробный индекс), проверка трёх условий тремя отдельными проходами — работает, но втрое дольше. Можно заменить множества битовыми масками по 9 битов.
::

::practice{title="54. Spiral Matrix"}
Вернуть элементы матрицы `m × n` в порядке обхода по спирали по часовой стрелке, начиная с левого верхнего угла. Пример: `[[1, 2, 3], [4, 5, 6], [7, 8, 9]]` → `[1, 2, 3, 6, 9, 8, 7, 4, 5]`. [Задача на LeetCode](https://leetcode.com/problems/spiral-matrix/)

#solution
Четыре границы: верхняя, нижняя, левая, правая. Проходим верхнюю строку и сдвигаем верхнюю границу вниз, правый столбец — правую влево, нижнюю строку справа налево, левый столбец снизу вверх. Нижнюю строку и левый столбец обходим, только если границы ещё не сошлись — иначе на матрице из одной строки или одного столбца элементы повторятся.

```ts
function spiralOrder(matrix: number[][]): number[] {
  const result: number[] = [];
  let top = 0;
  let bottom = matrix.length - 1;
  let left = 0;
  let right = matrix[0].length - 1;
  while (top <= bottom && left <= right) {
    for (let c = left; c <= right; c++) result.push(matrix[top][c]);
    top++;
    for (let r = top; r <= bottom; r++) result.push(matrix[r][right]);
    right--;
    if (top <= bottom) {
      for (let c = right; c >= left; c--) result.push(matrix[bottom][c]);
      bottom--;
    }
    if (left <= right) {
      for (let r = bottom; r >= top; r--) result.push(matrix[r][left]);
      left++;
    }
  }
  return result;
}
```

O(m · n) по времени. В проверке на случайных прямоугольных матрицах каждый элемент попал в ответ ровно один раз — в том числе на матрицах `1 × n` и `m × 1`, где без двух проверок `if` элементы дублируются.
::

::practice{title="48. Rotate Image"}
Повернуть квадратную матрицу `n × n` на 90° по часовой стрелке **на месте**, без второй матрицы. Пример: `[[1, 2, 3], [4, 5, 6], [7, 8, 9]]` → `[[7, 4, 1], [8, 5, 2], [9, 6, 3]]`. [Задача на LeetCode](https://leetcode.com/problems/rotate-image/)

#solution
Поворот — композиция двух отражений: транспонирование (отражение по главной диагонали) и отражение каждой строки слева направо. Оба делаются обменами на месте:

```ts
function rotate(matrix: number[][]): void {
  const n = matrix.length;
  for (let r = 0; r < n; r++) {               // транспонирование: отражение по диагонали
    for (let c = r + 1; c < n; c++) {
      [matrix[r][c], matrix[c][r]] = [matrix[c][r], matrix[r][c]];
    }
  }
  for (const row of matrix) row.reverse();     // отражение по вертикали
}
```

O(n²) по времени, O(1) по памяти. Ошибка — транспонировать с `c = 0` вместо `c = r + 1`: каждая пара поменяется дважды, и матрица вернётся в исходную. Поворот против часовой — транспонирование и разворот столбцов (или разворот строк, потом транспонирование). В проверке результат совпал с формулой `new[r][c] = old[n - 1 - c][r]`.
::

::practice{title="73. Set Matrix Zeroes"}
Если элемент матрицы равен 0, обнулить всю его строку и весь столбец. Сделать на месте. Продолжение: можно ли с O(1) дополнительной памяти? Пример: `[[0, 1, 2, 0], [3, 4, 5, 2], [1, 3, 1, 5]]` → `[[0, 0, 0, 0], [0, 4, 5, 0], [0, 3, 1, 0]]`. [Задача на LeetCode](https://leetcode.com/problems/set-matrix-zeroes/)

#solution
Обнулять сразу нельзя: новые нули обнулят лишние строки. Простое решение — два множества с номерами строк и столбцов, O(m + n) памяти. Для O(1) флаги хранят в самой матрице: первая строка отмечает столбцы, первый столбец — строки. Свои нули первой строки и столбца запоминаем заранее двумя переменными.

```ts
function setZeroes(matrix: number[][]): void {
  const m = matrix.length;
  const n = matrix[0].length;
  const firstRowZero = matrix[0].some((v) => v === 0);
  const firstColZero = matrix.some((row) => row[0] === 0);
  for (let r = 1; r < m; r++) {               // первая строка и столбец — флаги
    for (let c = 1; c < n; c++) {
      if (matrix[r][c] === 0) {
        matrix[r][0] = 0;
        matrix[0][c] = 0;
      }
    }
  }
  for (let r = 1; r < m; r++) {
    for (let c = 1; c < n; c++) {
      if (matrix[r][0] === 0 || matrix[0][c] === 0) matrix[r][c] = 0;
    }
  }
  if (firstRowZero) matrix[0].fill(0);
  if (firstColZero) for (const row of matrix) row[0] = 0;
}
```

O(m · n) по времени, O(1) по памяти. Порядок важен: первую строку и столбец обнуляем в самом конце, иначе потеряем флаги. В проверке результат совпал с решением на множествах на тысяче случайных матриц.
::

::practice{title="289. Game of Life"}
Поле «Жизни» Конвея: 1 — живая клетка, 0 — мёртвая. Следующее поколение: живая клетка с двумя или тремя живыми соседями (из восьми) выживает, иначе умирает; мёртвая с ровно тремя живыми соседями оживает. Все клетки меняются одновременно. Обновить поле на месте. [Задача на LeetCode](https://leetcode.com/problems/game-of-life/)

#solution
«Одновременно» значит, что соседей надо считать по старому состоянию. Копия поля решает это за O(m · n) памяти. Без копии храним оба состояния в одной клетке: младший бит — текущее, второй бит — следующее. Считаем соседей по младшему биту, записываем второй, а в конце сдвигаем все клетки вправо.

```ts
function gameOfLife(board: number[][]): void {
  const m = board.length;
  const n = board[0].length;
  // бит 0 — текущее состояние, бит 1 — следующее
  for (let r = 0; r < m; r++) {
    for (let c = 0; c < n; c++) {
      let alive = 0;
      for (let dr = -1; dr <= 1; dr++) {
        for (let dc = -1; dc <= 1; dc++) {
          if (dr === 0 && dc === 0) continue;
          const nr = r + dr;
          const nc = c + dc;
          if (nr >= 0 && nr < m && nc >= 0 && nc < n) alive += board[nr][nc] & 1;
        }
      }
      const live = board[r][c] & 1;
      if ((live && (alive === 2 || alive === 3)) || (!live && alive === 3)) board[r][c] |= 2;
    }
  }
  for (let r = 0; r < m; r++) for (let c = 0; c < n; c++) board[r][c] >>= 1;
}
```

O(m · n) по времени, O(1) по памяти. Ошибка — обновлять клетку сразу: соседи справа и снизу посчитают уже новое значение. Битовые операции разобраны в [Битовых операциях](/content/algorithms-data-structures/bit-manipulation). Продолжение — бесконечное поле: хранят только множество координат живых клеток.
::

## Красные флаги в ответе

- **Обновление клетки на месте, когда соседи считаются по старому состоянию.** Нужна копия или кодирование двух состояний.
- **Проверка границ, разбросанная по коду.** Один массив направлений и одна проверка выхода за пределы.
- **Обход по спирали без проверок `top <= bottom` и `left <= right` внутри цикла.** На одной строке или столбце элементы повторятся.
- **Поворот через вторую матрицу, когда просили на месте.** Транспонирование и разворот строк — O(1) памяти.
- **Путаница строк и столбцов**: `matrix[c][r]` вместо `matrix[r][c]` на неквадратной матрице — выход за границы.

## Как спрашивают на собеседовании

::question
Как повернуть матрицу на 90° на месте?

#answer
Транспонировать — поменять местами `matrix[r][c]` и `matrix[c][r]` для `c > r`, — затем развернуть каждую строку. Получится поворот по часовой стрелке. Время O(n²), память O(1).

#more
Против часовой — транспонировать и развернуть столбцы, или развернуть строки до транспонирования. Альтернатива — поворачивать по слоям, переставляя по четыре элемента за раз; это тоже O(1) памяти, но больше индексной арифметики. На неквадратной матрице на месте повернуть нельзя: меняются размеры.
::

::question
Как изменить матрицу, если новое значение клетки зависит от старых значений соседей?

#answer
Нельзя перезаписывать клетки по ходу обхода — соседи увидят уже новые значения. Варианты: работать с копией (O(m · n) памяти), хранить два состояния в одной клетке (в разных битах или через особые значения), а флаги для строк и столбцов хранить в первой строке и столбце самой матрицы.

#more
В «Жизни» младший бит — текущее состояние, второй — следующее, а в конце все клетки сдвигаются вправо. В обнулении строк и столбцов флаги лежат в первой строке и столбце, а их собственные нули запоминаются заранее. Вопрос проверяет понимание, что «одновременное» обновление требует разделять чтение и запись.
::

::question
Как обойти матрицу по спирали?

#answer
Держать четыре границы — верхнюю, нижнюю, левую и правую — и по очереди проходить верхнюю строку, правый столбец, нижнюю строку справа налево и левый столбец снизу вверх, сдвигая соответствующую границу после каждой стороны. Цикл идёт, пока границы не пересеклись. Время O(m · n).

#more
Нижнюю строку и левый столбец обходят только при `top <= bottom` и `left <= right`: на матрице из одной строки или столбца без этих проверок элементы попадут в ответ дважды. Альтернатива — моделировать движение с вектором направления и поворачивать при упоре в границу или уже посещённую клетку.
::
