# Утилиты

Маленькие библиотеки на каждый день: работа с массивами и объектами, даты, иммутабельность, HTTP, генерация id, склейка классов. Здесь особенно важен вопрос **«а нужна ли зависимость?»** - современный JavaScript умеет многое нативно.

---

## Сначала - нативный JS

За последние годы платформа догнала многое из того, ради чего тянули lodash:

```js
arr.at(-1);                          // последний элемент
arr.flatMap(fn); arr.flat();         // плоские массивы
Object.groupBy(items, (i) => i.type);// группировка (вместо _.groupBy)
structuredClone(obj);                // глубокая копия
arr.findLast(fn); arr.toSorted();    // иммутабельные методы массивов
```

<b class="text-on-semi-light">Принцип</b> - <span class="text-gray">Перед установкой утилиты проверь, нет ли нативного аналога. `Array.prototype`, `Object.*`, `Intl`, `structuredClone` покрывают большую часть бытовых задач без зависимостей и веса в бандле.</span>

---

## Общие утилиты

- **lodash** - исторический стандарт (дебаунс, throttle, глубокие операции, `groupBy`). Огромный; импортируй точечно (`lodash/debounce`), иначе тянет много. Сегодня нужен реже.
- **es-toolkit** - современная замена lodash: тот же набор, но **в разы легче**, на TypeScript, tree-shakeable. Растущий выбор 2025–2026.
- **Ramda** - утилиты в функциональном стиле (каррирование, композиция); нишевая, для FP-кода.

| Библиотека | Что          | Заметка                         |
| ---------- | ------------ | ------------------------------- |
| lodash     | всё          | тяжёлый, импортируй точечно      |
| es-toolkit | как lodash   | лёгкий, TS, современная замена   |
| Ramda      | FP-утилиты   | нишевая, функциональный стиль    |

## Даты

Работа с датами в JS традиционно болезненна (нативный `Date` неудобен и мутабелен). Библиотеки:

- **date-fns** - набор **модульных** функций (`format`, `addDays`), tree-shakeable, иммутабельные. Популярный современный выбор.
- **Day.js** - крошечный (~2 KB), API в стиле moment, плагины по требованию. Когда нужен минимальный вес.
- **Luxon** - мощная работа с таймзонами и интернационализацией; тяжелее.
- **moment.js** - легенда, но **legacy**: большой, мутабельный, в режиме поддержки. В новом коде не брать.

```js
import { format, addDays } from 'date-fns';
format(addDays(new Date(), 1), 'yyyy-MM-dd'); // date-fns: модульно и иммутабельно
```

<b class="text-on-semi-light">Temporal на горизонте</b> - <span class="text-gray">**Temporal** - новый нативный API дат (предложение TC39, уже въезжает в браузеры) - решает боли `Date`: иммутабельность, таймзоны, понятный API. Со временем он сделает date-библиотеки во многом ненужными. На собесе хорошо упомянуть, что индустрия движется к Temporal.</span>

## Иммутабельность

- **Immer** - даёт писать «мутирующий» код, а под капотом создаёт новые объекты. Незаменим для иммутабельных обновлений вложенного состояния (встроен в Redux Toolkit и Zustand).
- **Immutable.js** - собственные структуры данных (Map, List); тяжёлый и инвазивный - **legacy**, в новом коде избегают в пользу Immer + обычных объектов.

```js
import { produce } from 'immer';
const next = produce(state, (draft) => { draft.user.todos[0].done = true; }); // безопасная «мутация»
```

## HTTP-клиенты

- **fetch** - нативный, есть везде. Минусы: не бросает на 4xx/5xx (надо проверять `res.ok`), нет перехватчиков, многословный.
- **axios** - зрелый клиент: перехватчики (interceptors), авто-JSON, таймауты, отмена, удобные ошибки. Стандарт, когда нужны interceptors (например, подставлять токен).
- **ky** / **ofetch** - современные лёгкие обёртки над `fetch`: ретраи, хуки, авто-JSON, меньше веса, чем axios.

```js
// ky - тонкая обёртка над fetch с ретраями и хуками
import ky from 'ky';
const user = await ky.get('/api/users/1').json();
```

> Для большинства случаев хватает `fetch` (тем более внутри React Query/SWR, которым нужен лишь промис). axios берут, когда нужны перехватчики и развитая обработка ошибок.

## ID, классы и прочее

- **uuid** - стандартные UUID (v4 случайные, v7 сортируемые по времени). Нативный `crypto.randomUUID()` часто заменяет.
- **nanoid** - крошечный генератор коротких уникальных id, легче uuid.
- **clsx** / **classnames** - условная склейка `className` (`clsx('btn', { active })`); `clsx` - крошечный, де-факто стандарт, особенно с Tailwind.
- **query-string** - парсинг/сериализация query (хотя нативный `URLSearchParams` часто достаточно).

## Как мыслить про утилиты

```
Нужна одна функция (дебаунс)        → нативно или es-toolkit точечно
Много операций с данными            → es-toolkit (легче lodash)
Даты                                → date-fns / Day.js (ждём Temporal)
Иммутабельные обновления            → Immer
HTTP с перехватчиками               → axios; иначе fetch / ky
ID                                  → crypto.randomUUID() / nanoid
className                           → clsx
```

## Вопросы на собеседовании

<b class="text-on-semi-light">Нужен ли сегодня lodash?</b>
<span class="text-gray">Реже, чем раньше: многое есть нативно (`flatMap`, `Object.groupBy`, `structuredClone`, `at`). Если нужен набор утилит - современная лёгкая замена es-toolkit, и всегда импорт точечно.</span>

<b class="text-on-semi-light">Какую библиотеку дат выбрать и почему не moment?</b>
<span class="text-gray">date-fns (модульная, tree-shakeable) или Day.js (крошечный). moment - legacy: большой и мутабельный. На подходе нативный Temporal, который заменит большинство date-библиотек.</span>

<b class="text-on-semi-light">Зачем нужен Immer?</b>
<span class="text-gray">Писать иммутабельные обновления вложенного состояния как «мутацию» - под капотом создаются новые объекты. Встроен в Redux Toolkit и Zustand.</span>

<b class="text-on-semi-light">fetch или axios?</b>
<span class="text-gray">fetch - нативный, хватает в большинстве случаев (особенно внутри React Query). axios - когда нужны перехватчики, авто-JSON и развитая обработка ошибок. ky/ofetch - лёгкие обёртки над fetch.</span>

<b class="text-on-semi-light">Почему важно импортировать утилиты точечно?</b>
<span class="text-gray">Чтобы tree-shaking выкинул неиспользуемое. `import debounce from 'lodash/debounce'` не тянет весь lodash в бандл.</span>
