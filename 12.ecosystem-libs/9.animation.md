# Анимация

Простые переходы делает CSS, но сложная анимация - оркестрация последовательностей, жесты, физика пружин, layout-анимации, скролл-эффекты - требует библиотек. Здесь важно понимать, **когда хватит CSS, а когда нужна библиотека**, и чем отличаются подходы.

---

## CSS или библиотека?

| Задача                              | Чем делать                |
| ----------------------------------- | ------------------------- |
| hover, простой fade/slide           | CSS `transition`          |
| зацикленная декоративная анимация   | CSS `animation`/`@keyframes` |
| появление/уход элементов из DOM     | библиотека (или [Transition Vue](/content/vuejs/built-in-components)) |
| жесты (drag, swipe), физика          | библиотека (Motion, react-spring) |
| сложные таймлайны, скролл-сцены     | GSAP                      |
| анимация позиции при перестановке (FLIP) | Motion / AutoAnimate  |

> Базовые CSS-переходы, `transform`/`opacity` (которые анимируются на GPU) и производительность анимаций - в главе [CSS](/content/css). Библиотеки нужны там, где CSS неудобен или невозможен.

## Motion (ex-Framer Motion)

Стандарт декларативной анимации для React. Анимация описывается пропсами, библиотека берёт на себя всё остальное.

```jsx
import { motion } from 'motion/react';

<motion.div
  initial={{ opacity: 0, y: 20 }}
  animate={{ opacity: 1, y: 0 }}
  exit={{ opacity: 0 }}
  whileHover={{ scale: 1.05 }}
/>;
```

<b class="text-on-semi-light">Сильные стороны</b> - <span class="text-gray">Декларативность, жесты (`whileHover`, `drag`), **layout-анимации** (`layout` - автоматически анимирует изменение позиции/размера через FLIP), анимация появления/ухода (`AnimatePresence`). Раньше назывался Framer Motion; теперь это **Motion** - стал фреймворк-агностичным (есть и vanilla-версия).</span>

## GSAP

**GreenSock (GSAP)** - самый мощный и зрелый инструмент, **императивный**: ты строишь таймлайны и точно управляешь последовательностями.

```js
import gsap from 'gsap';
gsap.timeline()
  .to('.box', { x: 200, duration: 1 })
  .to('.box', { rotation: 360 }, '+=0.2'); // точный контроль последовательности
```

<b class="text-on-semi-light">Когда GSAP</b> - <span class="text-gray">Сложные оркестрованные сцены, скролл-анимации (ScrollTrigger), анимация SVG, морфинг - всё, где нужен точный таймлайн. Фреймворк-агностичен (работает с любым стеком). В 2025 GSAP стал полностью бесплатным, включая ранее платные плагины.</span>

## react-spring и другие

- **react-spring** - анимации на основе **физики пружин** (а не длительностей): естественное, «живое» движение. Хорош для интерактивных, прерываемых анимаций.
- **AutoAnimate** - **ноль конфигурации**: одна строка добавляет плавные переходы добавления/удаления/перестановки в списке. Когда нужно «просто чтобы плавно», без настройки.
- **Lottie** - проигрывает анимации из After Effects, экспортированные в JSON. Для сложной векторной графики/иллюстраций, сделанных дизайнерами.

```jsx
// AutoAnimate - одна строка, и список анимируется
const [parent] = useAutoAnimate();
<ul ref={parent}>{items.map(...)}</ul>;
```

## Vue и нативное

- **Vue** имеет встроенный `<Transition>`/`<TransitionGroup>` для появления/ухода и перестановки (см. [встроенные компоненты](/content/vuejs/built-in-components)); для сложного - **@vueuse/motion** или тот же GSAP.
- **View Transitions API** - **нативный** браузерный API для анимации переходов между состояниями/страницами (включая cross-document). Постепенно снижает потребность в библиотеках для переходов; знать про него - плюс на собесе.

---

## Как выбрать

```
Простой переход                      → CSS
React, декларативно + жесты + layout → Motion
Сложные таймлайны / скролл / SVG     → GSAP
Физика пружин, прерываемость         → react-spring
«Просто плавно» в списках            → AutoAnimate
Дизайнерская векторная анимация      → Lottie
Переходы между страницами            → View Transitions API
```

## Вопросы на собеседовании

<b class="text-on-semi-light">Когда хватает CSS, а когда нужна библиотека анимаций?</b>
<span class="text-gray">CSS - для hover, простых transition и зацикленных keyframes. Библиотека - для жестов, физики, оркестрованных таймлайнов, layout-анимаций и анимации появления/ухода из DOM.</span>

<b class="text-on-semi-light">Чем Motion отличается от GSAP?</b>
<span class="text-gray">Motion - декларативный (анимация через пропсы), силён в React, жестах и layout-анимациях. GSAP - императивный, с точными таймлайнами, незаменим для сложных сцен и скролл-анимаций; фреймворк-агностичен.</span>

<b class="text-on-semi-light">Что такое layout-анимации (FLIP)?</b>
<span class="text-gray">Автоматическая анимация изменения позиции/размера элемента при перестановке. Motion делает это пропом `layout`; техника FLIP измеряет «до/после» и анимирует разницу через transform.</span>

<b class="text-on-semi-light">Зачем анимировать transform/opacity, а не left/width?</b>
<span class="text-gray">`transform` и `opacity` анимируются на композиторе/GPU без reflow и repaint, поэтому плавные. Анимация геометрии (left/width) вызывает дорогой layout.</span>

<b class="text-on-semi-light">Что такое View Transitions API?</b>
<span class="text-gray">Нативный браузерный API для анимации переходов между состояниями и страницами. Снижает потребность в библиотеках для переходов.</span>
