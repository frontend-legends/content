# CSS

CSS — это не подбор свойств наугад, а несколько алгоритмов: каскад выбирает значение, раскладка расставляет боксы, отрисовка накладывает слои. На собеседовании проверяют, понимаешь ли ты их: почему стиль не применился, почему не работает `z-index`, что значит `flex: 1`, как анимировать без рывков и как организовать стили на большом проекте. Каждое утверждение главы проверено в настоящем Chromium — вычисленными стилями, координатами, пикселями скриншотов, — а изоляция стилей — сборкой Vite и компилятором Vue.

## Что спрашивают

- **Каскад** — специфичность, `!important`, каскадные слои, наследование и `inherit`, `initial`, `unset`, `revert`, единицы и блочная модель.
- **Селекторы** — `:is()`, `:where()`, `:has()`, `:focus-visible`, псевдоэлементы, как браузер сопоставляет селекторы.
- **Раскладка** — схлопывание отступов, BFC, позиционирование и containing block, контекст наложения, Flexbox, Grid, центрирование.
- **Адаптивность и движение** — media и container queries, единицы окна, `clamp()`, переходы, ключевые кадры, анимации по прокрутке.
- **Шрифты и эффекты** — загрузка шрифтов и `font-display`, вариативные шрифты, тени, фильтры, маски, градиенты.
- **Современный CSS и архитектура** — переменные и `@property`, вложенность, `oklch`, BEM, CSS Modules, `scoped`, Shadow DOM, слои и токены.
