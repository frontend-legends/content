# Современный JavaScript

ECMAScript обновляется каждый год. Знание актуальных фич показывает, что ты следишь за языком и пишешь идиоматичный код. На собеседованиях вопросы вроде «что нового в ES2022+?» или «как работает optional chaining?» - это проверка, живёшь ли ты в 2025 или застрял в ES5.

---

## ES2020

### Optional chaining - ?.

Безопасный доступ к вложенным свойствам без цепочки `&&`:

```js
// Было
const street = user && user.address && user.address.street;

// Стало
const street = user?.address?.street; // undefined если что-то в цепочке null/undefined
```

```js
// Работает с методами и индексами
user?.getName?.();      // вызов метода, если существует
users?.[0]?.name;       // доступ по индексу
```

### Nullish coalescing - ??

Возвращает правый операнд, только если левый - `null` или `undefined` (не `0`, не `''`, не `false`):

```js
// || считает falsy: 0, '', false, null, undefined
const count = data.count || 10;  // 0 -> 10 (неожиданно!)

// ?? считает nullish: только null и undefined
const count = data.count ?? 10;  // 0 -> 0 (корректно!)
const name = data.name ?? 'Anonymous'; // '' -> '' (корректно!)
```

### Другие фичи ES2020

```js
// BigInt - целые числа произвольной точности
const big = 9007199254740993n; // суффикс n
typeof big; // 'bigint'
big + 1n;   // 9007199254740994n (нельзя смешивать с number)

// Promise.allSettled - ждёт все промисы, не падает при reject
const results = await Promise.allSettled([
  fetch('/api/users'),
  fetch('/api/posts'),
  fetch('/api/broken') // даже если упадёт - получим результат
]);
// results: [{ status: 'fulfilled', value: ... }, { status: 'rejected', reason: ... }, ...]

// globalThis - единый глобальный объект для всех сред
console.log(globalThis); // window в браузере, global в Node.js, self в Worker

// Dynamic import - ленивая загрузка модулей
const module = await import('./heavy-module.js');
module.doStuff();
```

## ES2021

```js
// Logical assignment operators
let a = null;
a ??= 'default';  // a = a ?? 'default' -> 'default'
a ||= 'fallback'; // a = a || 'fallback'
a &&= transform(a); // a = a && transform(a)

// String.replaceAll
'aabbcc'.replaceAll('b', 'x'); // 'aaxxcc'
// До ES2021: 'aabbcc'.replace(/b/g, 'x')

// Promise.any - первый fulfilled (игнорирует rejected)
const first = await Promise.any([
  fetch('/cdn1/data'),
  fetch('/cdn2/data'),
  fetch('/cdn3/data')
]); // первый успешный ответ

// Numeric separators - визуальное разделение цифр
const billion = 1_000_000_000;
const hex = 0xFF_FF_FF;
const binary = 0b1010_0001;
```

<span class="text-gray">WeakRef и FinalizationRegistry тоже вошли в ES2021, подробно разобраны в [Метапрограммирование](/content/javascript/metaprogramming).</span>

## ES2022

### Top-level await

`await` вне async-функции - на верхнем уровне ESM-модуля:

```js
// config.js (ESM)
const response = await fetch('/api/config');
export const config = await response.json();

// main.js
import { config } from './config.js'; // ждёт загрузки config
```

<span class="text-gray">Работает только в ESM (не CommonJS). Модуль, использующий top-level await, блокирует загрузку зависящих от него модулей.</span>

### Array.at()

Доступ к элементам с конца через отрицательный индекс:

```js
const arr = [1, 2, 3, 4, 5];

arr.at(0);   // 1
arr.at(-1);  // 5 (последний)
arr.at(-2);  // 4

// Раньше: arr[arr.length - 1]
// Работает и со строками: 'hello'.at(-1) -> 'o'
```

### Другие фичи ES2022

```js
// Object.hasOwn() - замена obj.hasOwnProperty()
const obj = { name: 'Alice' };
Object.hasOwn(obj, 'name');     // true
Object.hasOwn(obj, 'toString'); // false (из прототипа)
// Безопаснее: работает с Object.create(null)

// Error cause - цепочка причин ошибок
try {
  await fetch('/api/data');
} catch (err) {
  throw new Error('Failed to load data', { cause: err });
}
// error.cause -> оригинальная ошибка

// Private fields и methods (class)
class User {
  #password; // приватное поле

  constructor(name, password) {
    this.name = name;
    this.#password = password;
  }

  #validate() { // приватный метод
    return this.#password.length >= 8;
  }

  isValid() {
    return this.#validate();
  }
}

const user = new User('Alice', 'secret123');
user.#password; // SyntaxError: Private field
```

## ES2023

### Change Array by copy

Новые методы массивов, которые возвращают **копию** вместо мутации оригинала:

```js
const arr = [3, 1, 4, 1, 5];

// Мутирующие         // Копирующие (ES2023)
arr.sort();           arr.toSorted();          // [1, 1, 3, 4, 5]
arr.reverse();        arr.toReversed();        // [5, 1, 4, 1, 3]
arr.splice(1, 1);     arr.toSpliced(1, 1);     // [3, 4, 1, 5]
arr[0] = 99;          arr.with(0, 99);         // [99, 1, 4, 1, 5]
```

<b class="text-on-semi-light">Зачем:</b> <span class="text-gray">Immutable операции критичны для React (state нельзя мутировать), Redux, и любого кода, следующего принципу immutability. Раньше приходилось писать `[...arr].sort()` - теперь есть нативный способ.</span>

### Array find from last

```js
const users = [
  { name: 'Alice', role: 'admin' },
  { name: 'Bob', role: 'user' },
  { name: 'Charlie', role: 'admin' }
];

// Поиск с конца
users.findLast(u => u.role === 'admin');
// { name: 'Charlie', role: 'admin' }

users.findLastIndex(u => u.role === 'admin');
// 2
```

### Hashbang

```js
#!/usr/bin/env node
// Теперь валидный JavaScript-синтаксис
console.log('CLI tool started');
```

## ES2024

```js
// Object.groupBy() - группировка элементов
const products = [
  { name: 'Apple', category: 'fruit' },
  { name: 'Carrot', category: 'vegetable' },
  { name: 'Banana', category: 'fruit' }
];

Object.groupBy(products, (p) => p.category);
// {
//   fruit: [{ name: 'Apple', ... }, { name: 'Banana', ... }],
//   vegetable: [{ name: 'Carrot', ... }]
// }

// Map.groupBy() - когда ключи не строки
Map.groupBy(products, (p) => p.category);
```

```js
// Promise.withResolvers() - удобное создание deferred promise
const { promise, resolve, reject } = Promise.withResolvers();

// Раньше:
// let resolve, reject;
// const promise = new Promise((res, rej) => { resolve = res; reject = rej; });

setTimeout(() => resolve('done'), 1000);
const result = await promise; // 'done'
```

```js
// ArrayBuffer transfer - перемещение буфера без копирования
const buffer = new ArrayBuffer(1024);
const transferred = buffer.transfer(); // buffer становится detached (0 байт)
// transferred содержит данные оригинала
```

## ES2025

```js
// Set methods - теоретико-множественные операции
const a = new Set([1, 2, 3, 4]);
const b = new Set([3, 4, 5, 6]);

a.union(b);              // Set {1, 2, 3, 4, 5, 6}
a.intersection(b);       // Set {3, 4}
a.difference(b);         // Set {1, 2}
a.symmetricDifference(b); // Set {1, 2, 5, 6}
a.isSubsetOf(b);         // false
a.isSupersetOf(b);       // false
a.isDisjointFrom(b);     // false

// RegExp modifiers - inline флаги
// (?i:pattern) - case-insensitive для части паттерна
/hello (?i:world)/.test('hello World'); // true
/hello (?i:world)/.test('Hello World'); // false (hello без i)
```

## JSON

### JSON.parse() и JSON.stringify()

```js
// Базовое использование
const obj = { name: 'Alice', age: 25 };
const json = JSON.stringify(obj);  // '{"name":"Alice","age":25}'
const parsed = JSON.parse(json);   // { name: 'Alice', age: 25 }
```

### Replacer и reviver

```js
// replacer - фильтрация/трансформация при stringify
const user = { name: 'Alice', password: 'secret', age: 25 };

// Как массив - whitelist полей
JSON.stringify(user, ['name', 'age']);
// '{"name":"Alice","age":25}'

// Как функция - трансформация
JSON.stringify(user, (key, value) => {
  if (key === 'password') return undefined; // исключаем
  return value;
});
// '{"name":"Alice","age":25}'
```

```js
// reviver - трансформация при parse
const json = '{"name":"Alice","createdAt":"2025-01-15T10:00:00Z"}';

const obj = JSON.parse(json, (key, value) => {
  if (key === 'createdAt') return new Date(value); // строка -> Date
  return value;
});

console.log(obj.createdAt instanceof Date); // true
```

### Prettify и toJSON

```js
// Третий аргумент - отступы для форматирования
JSON.stringify({ a: 1, b: { c: 2 } }, null, 2);
// {
//   "a": 1,
//   "b": {
//     "c": 2
//   }
// }

// toJSON() - кастомная сериализация объекта
class User {
  constructor(name, password) {
    this.name = name;
    this.password = password;
  }

  toJSON() {
    return { name: this.name }; // password не попадёт в JSON
  }
}

JSON.stringify(new User('Alice', 'secret'));
// '{"name":"Alice"}'
```

### structuredClone() vs JSON deep copy

```js
// JSON deep copy - старый хак
const copy = JSON.parse(JSON.stringify(original));
// Проблемы: теряет Date (-> string), undefined, функции, Map, Set, RegExp, циклические ссылки

// structuredClone() - правильный deep copy (ES2022+)
const original = {
  date: new Date(),
  set: new Set([1, 2, 3]),
  nested: { deep: { value: 42 } }
};

const clone = structuredClone(original);
clone.nested.deep.value = 0;
console.log(original.nested.deep.value); // 42 (не затронут)
console.log(clone.date instanceof Date); // true (корректно!)
console.log(clone.set instanceof Set);   // true (корректно!)
```

| Метод                           | Date | Map/Set | Функции | Циклические ссылки | undefined |
| ------------------------------- | ---- | ------- | ------- | ------------------- | --------- |
| `JSON.parse(JSON.stringify())` | Нет  | Нет     | Нет     | Ошибка              | Теряет    |
| `structuredClone()`            | Да   | Да      | Нет     | Да                  | Да        |
| Spread `{...obj}`             | -    | -       | Да      | Нет                 | Да        |

<span class="text-gray">Spread и Object.assign делают только shallow copy - вложенные объекты копируются по ссылке. structuredClone - полноценный deep copy для большинства типов.</span>

## Intl API

Intl - встроенный API для интернационализации: форматирование чисел, дат, текста с учётом локали.

### Intl.NumberFormat

```js
// Форматирование валюты
new Intl.NumberFormat('ru-RU', {
  style: 'currency', currency: 'RUB'
}).format(1234567.89);
// '1 234 567,89 ₽'

new Intl.NumberFormat('en-US', {
  style: 'currency', currency: 'USD'
}).format(1234567.89);
// '$1,234,567.89'

// Compact notation
new Intl.NumberFormat('ru-RU', {
  notation: 'compact', compactDisplay: 'short'
}).format(1500000);
// '1,5 млн'

// Проценты
new Intl.NumberFormat('ru-RU', {
  style: 'percent', maximumFractionDigits: 1
}).format(0.856);
// '85,6%'
```

### Intl.DateTimeFormat

```js
new Intl.DateTimeFormat('ru-RU', {
  year: 'numeric', month: 'long', day: 'numeric', weekday: 'long'
}).format(new Date('2025-07-28'));
// 'понедельник, 28 июля 2025 г.'

new Intl.DateTimeFormat('en-US', {
  dateStyle: 'full', timeStyle: 'short'
}).format(new Date());
// 'Monday, July 28, 2025 at 10:30 AM'
```

### Intl.RelativeTimeFormat

```js
const rtf = new Intl.RelativeTimeFormat('ru', { numeric: 'auto' });

rtf.format(-1, 'day');    // 'вчера'
rtf.format(-3, 'day');    // '3 дня назад'
rtf.format(1, 'hour');    // 'через 1 час'
rtf.format(2, 'month');   // 'через 2 месяца'
```

### Intl.PluralRules и Intl.Segmenter

```js
// PluralRules - правильное склонение
const pr = new Intl.PluralRules('ru');
pr.select(1);   // 'one'    -> '1 комментарий'
pr.select(2);   // 'few'    -> '2 комментария'
pr.select(5);   // 'many'   -> '5 комментариев'
pr.select(21);  // 'one'    -> '21 комментарий'

// Segmenter - разбиение текста на слова/предложения/графемы
const segmenter = new Intl.Segmenter('ru', { granularity: 'word' });
const segments = [...segmenter.segment('Привет, мир!')];
// [{ segment: 'Привет', ... }, { segment: ',', ... }, ...]
```

<span class="text-gray">Intl API работает нативно, без библиотек. Поддержка локалей зависит от браузера/ОС, но основные (en, ru, de, zh) поддерживаются везде. Для edge cases - полифилл FormatJS.</span>

## Date и Temporal

### Проблемы Date

`Date` в JavaScript создан в 1995 году (скопирован из Java) и имеет фундаментальные проблемы:

```js
// 1. Mutable
const date = new Date('2025-07-28');
date.setMonth(0); // мутирует оригинал!

// 2. Месяцы с нуля
new Date(2025, 0, 1);  // 1 января (0 = январь)
new Date(2025, 11, 1); // 1 декабря (11 = декабрь)

// 3. Парсинг непредсказуем
new Date('2025-01-01');          // UTC
new Date('2025/01/01');          // Local time (зависит от браузера!)
new Date('01/02/2025');          // 2 января или 1 февраля? Зависит от локали

// 4. Timezone hell
// Нет встроенного способа работать с произвольными timezone
// Нет типа "только дата" или "только время"
```

### Temporal proposal

Temporal - новый API для работы с датами и временем. Stage 3 в TC39, ожидается в движках.

```js
// PlainDate - дата без времени и timezone
const date = Temporal.PlainDate.from('2025-07-28');
const nextWeek = date.add({ days: 7 }); // immutable - новый объект
console.log(nextWeek.toString()); // '2025-08-04'
console.log(date.month); // 7 (не 6!)

// PlainTime - время без даты
const time = Temporal.PlainTime.from('14:30:00');
const later = time.add({ hours: 2 });

// ZonedDateTime - полная дата+время+timezone
const meeting = Temporal.ZonedDateTime.from({
  timeZone: 'Europe/Moscow',
  year: 2025, month: 7, day: 28,
  hour: 15, minute: 0
});
const inNY = meeting.withTimeZone('America/New_York');
// Автоматическая конвертация между timezone

// Duration - длительность
const duration = Temporal.Duration.from({ hours: 2, minutes: 30 });
const total = duration.total('minutes'); // 150
```

| Проблема Date          | Решение Temporal                              |
| ---------------------- | --------------------------------------------- |
| Mutable                | Все объекты immutable                         |
| Месяцы с нуля          | Месяцы с 1 (как в реальной жизни)             |
| Нет «только дата»      | PlainDate, PlainTime, PlainYearMonth          |
| Timezone hell          | ZonedDateTime с IANA timezone                 |
| Непредсказуемый парсинг| Строгий ISO 8601 формат                       |
| Нет длительности       | Duration с арифметикой                        |

<span class="text-gray">Пока Temporal не доступен нативно, используй `date-fns` (функциональный, tree-shakeable) или `dayjs` (лёгкий, Moment-совместимый API). Polyfill Temporal: `@js-temporal/polyfill`. Подробнее о типах данных -> [Типы и переменные](/content/javascript/types-and-variables). О модульной системе и dynamic import -> [Модули](/content/javascript/modules).</span>

## Частые вопросы на собесе

**В чём разница между ?? и ||?**
`||` возвращает правый операнд при любом falsy значении (0, '', false, null, undefined). `??` - только при null или undefined. Для чисел и строк `??` безопаснее: `0 ?? 10` вернёт 0, а `0 || 10` вернёт 10.

**Что такое optional chaining?**
`?.` - оператор безопасного доступа. `user?.address?.street` вернёт undefined, если user или address равны null/undefined, вместо TypeError. Работает с методами (`obj?.method?.()`) и индексами (`arr?.[0]`).

**Зачем toSorted вместо sort?**
`sort()` мутирует массив, `toSorted()` возвращает новый. Immutable операции критичны для React state, Redux, и любого кода, где мутация вызывает баги. Также есть `toReversed()`, `toSpliced()`, `with()`.

**Как сделать deep copy объекта?**
`structuredClone(obj)` - нативный deep copy, поддерживает Date, Map, Set, циклические ссылки. `JSON.parse(JSON.stringify())` - старый хак, теряет Date, Map, Set, функции, undefined. Spread `{...obj}` - только shallow copy.

**Что такое Intl API?**
Встроенный API для интернационализации: форматирование чисел (`Intl.NumberFormat`), дат (`Intl.DateTimeFormat`), относительного времени (`Intl.RelativeTimeFormat`), множественного числа (`Intl.PluralRules`). Работает нативно, без библиотек, учитывает локаль.

**Зачем нужен Temporal?**
Date в JS имеет фундаментальные проблемы: mutable, месяцы с нуля, нет timezone support, непредсказуемый парсинг. Temporal предоставляет immutable типы (PlainDate, ZonedDateTime, Duration), месяцы с 1, строгий парсинг, полноценные timezone.
