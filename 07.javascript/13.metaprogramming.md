# Метапрограммирование

Метапрограммирование - это код, который изменяет или контролирует поведение другого кода. В JavaScript это Proxy, Reflect, Symbol, WeakMap/WeakSet/WeakRef. Эти инструменты используются внутри фреймворков (реактивность Vue 3, dependency injection в Angular) и в production-библиотеках. На собеседованиях вопросы по metaprogramming отделяют тех, кто «пишет на JS», от тех, кто **понимает JS**.

---

## Proxy

Proxy - объект-обёртка, который перехватывает операции с целевым объектом (чтение, запись, удаление, вызов) и позволяет определить кастомное поведение.

### Синтаксис

```js
const proxy = new Proxy(target, handler);
```

- <b class="text-on-semi-light">target</b> - <span class="text-gray">оригинальный объект, который оборачиваем</span>
- <b class="text-on-semi-light">handler</b> - <span class="text-gray">объект с «ловушками» (traps) - функциями, перехватывающими операции</span>

### Основные traps

| Trap               | Перехватывает                  | Пример вызова                  |
| ------------------ | ------------------------------ | ------------------------------ |
| `get`              | Чтение свойства                | `proxy.name`                   |
| `set`              | Запись свойства                | `proxy.name = 'Alice'`         |
| `has`              | Оператор `in`                  | `'name' in proxy`              |
| `deleteProperty`   | Оператор `delete`              | `delete proxy.name`            |
| `apply`            | Вызов функции                  | `proxy(args)`                  |
| `construct`        | Оператор `new`                 | `new proxy(args)`              |
| `ownKeys`          | `Object.keys`, `for...in`      | `Object.keys(proxy)`          |
| `getOwnPropertyDescriptor` | `Object.getOwnPropertyDescriptor` | Дескриптор свойства |
| `defineProperty`   | `Object.defineProperty`        | Определение свойства           |
| `getPrototypeOf`   | `Object.getPrototypeOf`        | Чтение прототипа               |

### Пример: валидация при записи

```js
const user = { name: 'Alice', age: 25 };

const validated = new Proxy(user, {
  set(target, prop, value) {
    if (prop === 'age') {
      if (typeof value !== 'number' || value < 0 || value > 150) {
        throw new TypeError('Age must be a number between 0 and 150');
      }
    }
    target[prop] = value;
    return true; // set trap должен возвращать true при успехе
  }
});

validated.age = 30;  // OK
validated.age = -5;  // TypeError: Age must be a number between 0 and 150
```

### Пример: логирование доступа

```js
function createLogger(obj) {
  return new Proxy(obj, {
    get(target, prop) {
      console.log(`[GET] ${String(prop)}`);
      return Reflect.get(target, prop);
    },
    set(target, prop, value) {
      console.log(`[SET] ${String(prop)} = ${value}`);
      return Reflect.set(target, prop, value);
    }
  });
}

const data = createLogger({ count: 0 });
data.count;     // [GET] count
data.count = 5; // [SET] count = 5
```

### Reactive data (как Vue 3)

Vue 3 использует Proxy для реактивности: `get` trap отслеживает зависимости (track), `set` trap уведомляет об изменениях (trigger). Зависимости хранятся в WeakMap -> Map -> Set. При чтении свойства в computed/watcher - зависимость регистрируется. При записи - все зависимые эффекты перезапускаются.

<span class="text-gray">Подробнее -> [Реактивность Vue](/content/vuejs/reactivity-deep-dive).</span>

### Revocable Proxy

`Proxy.revocable()` создаёт proxy, который можно «отключить»:

```js
const { proxy, revoke } = Proxy.revocable({ secret: '42' }, {
  get(target, prop) {
    return Reflect.get(target, prop);
  }
});

console.log(proxy.secret); // '42'
revoke();
console.log(proxy.secret); // TypeError: Cannot perform 'get' on a proxy that has been revoked
```

<b class="text-on-semi-light">Use case:</b> <span class="text-gray">Передаёшь объект стороннему коду и хочешь гарантировать, что доступ будет отозван после определённого момента. Security-паттерн для API с ограниченным временем жизни.</span>

## Reflect API

Reflect - встроенный объект с методами, зеркально отражающими операции Proxy traps. Каждому trap соответствует метод Reflect.

### Основные методы

```js
Reflect.get(target, prop);           // target[prop]
Reflect.set(target, prop, value);    // target[prop] = value
Reflect.has(target, prop);           // prop in target
Reflect.deleteProperty(target, prop); // delete target[prop]
Reflect.ownKeys(target);             // Object.keys + symbols
Reflect.apply(fn, thisArg, args);    // fn.apply(thisArg, args)
Reflect.construct(Class, args);      // new Class(...args)
```

### Почему Reflect вместо прямого доступа

```js
// Без Reflect - проблемы с наследованием и receiver
const handler = {
  get(target, prop) {
    return target[prop]; // теряем receiver (this)
  }
};

// С Reflect - корректная передача receiver
const handler2 = {
  get(target, prop, receiver) {
    return Reflect.get(target, prop, receiver); // this = receiver
  }
};
```

Причины использовать Reflect:

1. **Корректный receiver** - `Reflect.get` передаёт `receiver`, что критично для наследования через Proxy
2. **Возвращает boolean** - `Reflect.set` возвращает `true/false` вместо выбрасывания ошибки
3. **Консистентный API** - один набор методов для всех операций с объектами
4. **1-к-1 соответствие с traps** - каждый trap имеет зеркальный Reflect метод

## Symbol

Symbol - примитивный тип данных, создающий **уникальные идентификаторы**. Два Symbol'а никогда не равны, даже с одинаковым описанием.

### Создание

```js
const s1 = Symbol();
const s2 = Symbol('description'); // описание для отладки
const s3 = Symbol('description');

console.log(s2 === s3); // false - каждый Symbol уникален
console.log(s2.description); // 'description'
```

### Global Symbol Registry

```js
// Symbol.for() создаёт/находит Symbol в глобальном реестре
const g1 = Symbol.for('shared');
const g2 = Symbol.for('shared');

console.log(g1 === g2); // true - один и тот же Symbol из реестра

Symbol.keyFor(g1); // 'shared' - обратный поиск
Symbol.keyFor(s2); // undefined - не в реестре
```

### Symbol как ключи объектов

```js
const id = Symbol('id');
const user = {
  name: 'Alice',
  [id]: 123 // Symbol как ключ
};

console.log(user[id]); // 123

// Symbol-ключи НЕ видны в:
Object.keys(user);           // ['name']
Object.entries(user);        // [['name', 'Alice']]
JSON.stringify(user);        // '{"name":"Alice"}'
for (const key in user) {}   // только 'name'

// Но доступны через:
Object.getOwnPropertySymbols(user); // [Symbol(id)]
Reflect.ownKeys(user);              // ['name', Symbol(id)]
```

<b class="text-on-semi-light">Use case:</b> <span class="text-gray">Symbol-ключи - способ добавить «скрытые» свойства, которые не конфликтуют с обычными и не появляются в сериализации. Библиотеки используют это для metadata.</span>

### Well-known Symbols

Встроенные Symbol'ы, управляющие поведением объектов:

```js
// Symbol.iterator - определяет протокол итерации
const range = {
  from: 1,
  to: 5,
  [Symbol.iterator]() {
    let current = this.from;
    const last = this.to;
    return {
      next() {
        return current <= last
          ? { value: current++, done: false }
          : { done: true };
      }
    };
  }
};

for (const n of range) console.log(n); // 1, 2, 3, 4, 5
```

```js
// Symbol.toPrimitive - кастомное преобразование к примитиву
const money = {
  amount: 100,
  currency: 'USD',
  [Symbol.toPrimitive](hint) {
    if (hint === 'number') return this.amount;
    if (hint === 'string') return `${this.amount} ${this.currency}`;
    return this.amount; // default
  }
};

console.log(+money);      // 100
console.log(`${money}`);  // '100 USD'
console.log(money + 50);  // 150
```

```js
// Symbol.hasInstance - кастомный instanceof
class Even {
  static [Symbol.hasInstance](num) {
    return typeof num === 'number' && num % 2 === 0;
  }
}

console.log(4 instanceof Even);  // true
console.log(3 instanceof Even);  // false
```

```js
// Symbol.toStringTag - кастомный Object.prototype.toString
class MyClass {
  get [Symbol.toStringTag]() {
    return 'MyAwesomeClass';
  }
}

console.log(Object.prototype.toString.call(new MyClass()));
// '[object MyAwesomeClass]'
```

## WeakMap

WeakMap - коллекция пар ключ-значение, где **ключи - только объекты** (или Symbol), и они удерживаются «слабо» - GC может удалить объект-ключ, если на него больше нет других ссылок.

```js
const wm = new WeakMap();
let obj = { data: 'important' };

wm.set(obj, 'metadata');
console.log(wm.get(obj)); // 'metadata'

obj = null; // GC может удалить объект и запись в WeakMap
```

### Отличия от Map

| Свойство          | Map                    | WeakMap                  |
| ----------------- | ---------------------- | ------------------------ |
| **Ключи**         | Любые значения         | Только объекты / Symbol  |
| **GC**            | Удерживает ключи       | Не препятствует GC       |
| **Итерация**      | `for...of`, `.keys()`  | Нет (нет итерации)       |
| **Размер**        | `.size`                | Нет `.size`              |
| **Use case**      | Общее хранение         | Metadata, private data   |

### Практические use cases

```js
// 1. Private data для классов (до приватных полей #)
const privateData = new WeakMap();

class User {
  constructor(name, password) {
    this.name = name;
    privateData.set(this, { password });
  }

  checkPassword(pwd) {
    return privateData.get(this).password === pwd;
  }
}

const user = new User('Alice', 'secret');
user.checkPassword('secret'); // true
// privateData не доступна снаружи, и GC очистит запись при удалении user
```

```js
// 2. Кэширование результатов вычислений
const cache = new WeakMap();

function heavyComputation(obj) {
  if (cache.has(obj)) return cache.get(obj);

  const result = /* ...тяжёлые вычисления... */ obj.value * 2;
  cache.set(obj, result);
  return result;
}

// Когда obj удаляется - кэш автоматически очищается
```

```js
// 3. DOM metadata
const elementData = new WeakMap();

function trackElement(el) {
  elementData.set(el, {
    clickCount: 0,
    lastInteraction: null
  });
}

// Когда DOM-элемент удаляется со страницы и GC его собирает -
// metadata в WeakMap тоже очищается автоматически
```

## WeakSet

WeakSet - коллекция уникальных объектов со слабыми ссылками. Аналог WeakMap, но хранит только ключи (без значений).

```js
const visited = new WeakSet();

function processNode(node) {
  if (visited.has(node)) return; // уже обработан
  visited.add(node);
  // ...обработка
}

// Когда node удаляется из DOM и GC его собирает -
// запись в WeakSet удаляется автоматически
```

<b class="text-on-semi-light">Типичные use cases:</b> <span class="text-gray">Отслеживание «уже обработанных» объектов, предотвращение циклических обходов, маркировка объектов без изменения самих объектов.</span>

## WeakRef и FinalizationRegistry

### WeakRef

WeakRef создаёт **слабую ссылку** на объект - ссылку, которая не предотвращает сборку мусора.

```js
let target = { data: 'heavy payload' };
const weakRef = new WeakRef(target);

console.log(weakRef.deref()); // { data: 'heavy payload' }

target = null; // убираем сильную ссылку

// Через какое-то время (после GC):
console.log(weakRef.deref()); // undefined (объект собран GC)
```

⚠️ **Важно:** `deref()` может вернуть `undefined` в любой момент после удаления сильных ссылок. Нельзя полагаться на то, что GC сработает или не сработает в конкретный момент.

### FinalizationRegistry

FinalizationRegistry позволяет зарегистрировать callback, который вызывается, когда зарегистрированный объект собирается GC:

```js
const registry = new FinalizationRegistry((heldValue) => {
  console.log(`Object with id "${heldValue}" was garbage collected`);
  // Очистка: закрыть файл, отменить подписку, удалить из кэша...
});

let obj = { heavy: new ArrayBuffer(1024 * 1024) };
registry.register(obj, 'my-object-id'); // heldValue = 'my-object-id'

obj = null;
// Когда-то позже: "Object with id "my-object-id" was garbage collected"
```

### Пример: кэш с WeakRef

```js
class WeakCache {
  #cache = new Map();
  #registry = new FinalizationRegistry((key) => {
    // Очищаем запись в Map, когда объект собран GC
    const ref = this.#cache.get(key);
    if (ref && !ref.deref()) this.#cache.delete(key);
  });

  set(key, value) {
    this.#cache.set(key, new WeakRef(value));
    this.#registry.register(value, key);
  }

  get(key) {
    const ref = this.#cache.get(key);
    if (!ref) return undefined;
    const value = ref.deref();
    if (!value) {
      this.#cache.delete(key); // Объект уже собран
      return undefined;
    }
    return value;
  }
}
```

<span class="text-gray">WeakRef и FinalizationRegistry - low-level инструменты. Спецификация явно говорит: не полагайтесь на детерминированное поведение GC. Используйте только когда explicit cleanup невозможен или нецелесообразен. Подробнее о работе GC -> [Память и производительность](/content/javascript/memory-and-performance).</span>

## Когда использовать что

| Инструмент              | Когда использовать                                        |
| ----------------------- | --------------------------------------------------------- |
| **Proxy**               | Перехват операций: валидация, logging, reactive data      |
| **Reflect**             | Внутри Proxy traps для корректного forwarding             |
| **Symbol**              | Уникальные ключи, протоколы (iterator, toPrimitive)       |
| **WeakMap**             | Metadata для объектов, private data, кэш                  |
| **WeakSet**             | Маркировка объектов (visited, processed)                  |
| **WeakRef**             | Кэш без предотвращения GC                                |
| **FinalizationRegistry**| Cleanup при GC объекта                                    |

## Частые вопросы на собесе

**Что такое Proxy и зачем он нужен?**
Proxy перехватывает операции с объектом (чтение, запись, удаление, вызов) через handler с traps. Используется для валидации, логирования, реактивности (Vue 3), создания «умных» объектов. Не путать с Proxy-сервером - это JavaScript Proxy.

**В чём разница между Map и WeakMap?**
В WeakMap ключи - только объекты, и они удерживаются слабо: GC может собрать объект-ключ, если на него нет других ссылок. WeakMap не итерируемый, нет `.size`. Use case - metadata для объектов без утечек памяти.

**Зачем нужен Reflect, если можно обращаться к объекту напрямую?**
Reflect корректно передаёт receiver (this) в Proxy traps, возвращает boolean вместо исключений и обеспечивает 1-к-1 соответствие с trap-методами. Это правильный способ «пробрасывать» операцию к оригинальному объекту внутри trap.

**Что такое Symbol.iterator?**
Well-known Symbol, определяющий протокол итерации. Если объект имеет метод `[Symbol.iterator]()`, он может использоваться в `for...of`, spread, destructuring. Это то, что делает массивы, строки, Map, Set итерируемыми.

**Когда использовать WeakRef?**
Когда нужна ссылка на объект, но не хочешь предотвращать его сборку GC. Типичный use case - кэш, где объекты могут быть пересозданы. Важно: `deref()` может вернуть `undefined` в любой момент, нельзя полагаться на timing GC.
