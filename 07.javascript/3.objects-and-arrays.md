# Объекты и массивы

Объекты и массивы - основные структуры данных в JavaScript. Практически всё, с чем ты работаешь во фронтенде - props компонентов, ответы API, state приложения - это объекты и массивы. На собеседовании проверяют не только синтаксис, но и понимание ссылочной семантики, мутабельности, выбор правильного метода и знание современных альтернатив (Map, Set).

---

## Объекты

### Создание объектов

```js
// 1. Object literal - основной способ
const user = {
  name: "Alice",
  age: 30,
  "full-name": "Alice Smith", // ключ с дефисом - только в кавычках
};

// 2. Object constructor (не используй)
const obj = new Object();

// 3. Object.create - создание с указанным прототипом
const proto = { greet() { return "Hi"; } };
const child = Object.create(proto);
child.greet(); // "Hi" - метод из прототипа

// 4. Object.create(null) - объект без прототипа (чистый словарь)
const dict = Object.create(null);
dict.toString; // undefined - нет Object.prototype
```

### Доступ к свойствам

```js
user.name;           // dot notation
user["full-name"];   // bracket notation (для динамических ключей и спецсимволов)

const key = "age";
user[key];           // 30 - динамический доступ

// Optional chaining
user.address?.city;  // undefined (не TypeError)
user.getName?.();    // undefined (если метод не существует)
```

## Методы Object

```js
const config = { host: "localhost", port: 3000, debug: true };

// Получение ключей, значений, пар
Object.keys(config);    // ["host", "port", "debug"]
Object.values(config);  // ["localhost", 3000, true]
Object.entries(config); // [["host","localhost"], ["port",3000], ["debug",true]]

// Обратная операция
Object.fromEntries([["a", 1], ["b", 2]]); // { a: 1, b: 2 }

// Копирование / слияние (shallow)
Object.assign({}, config, { port: 8080 }); // { host: "localhost", port: 8080, debug: true }

// Проверка свойства
Object.hasOwn(config, "host"); // true (ES2022, замена obj.hasOwnProperty())

// Заморозка
Object.freeze(config);       // нельзя добавлять, удалять, изменять свойства
Object.isFrozen(config);     // true

// Запечатывание
Object.seal(config);         // нельзя добавлять/удалять, но можно изменять
Object.isSealed(config);     // true

// Определение свойства с дескриптором
Object.defineProperty(config, "secret", {
  value: "hidden",
  enumerable: false,   // не видно в for...in, Object.keys()
  writable: false,     // нельзя изменить
  configurable: false, // нельзя удалить или переконфигурировать
});
```

<span class="text-gray">`Object.freeze()` и `Object.seal()` работают **shallow** - вложенные объекты остаются мутабельными. Для deep freeze нужна рекурсивная функция или библиотека.</span>

## Spread и копирование объектов

```js
const original = { a: 1, b: { c: 2 } };

// Shallow copy (spread)
const shallow = { ...original };
shallow.a = 99;        // original.a не затронут
shallow.b.c = 99;      // original.b.c === 99 - вложенный объект общий!

// Shallow copy (Object.assign)
const shallow2 = Object.assign({}, original);

// Deep copy (structuredClone) - ES2022
const deep = structuredClone(original);
deep.b.c = 99;         // original.b.c === 2 - полностью независимая копия
```

<b class="text-on-semi-light">structuredClone():</b> Нативный deep clone. Копирует вложенные объекты, массивы, Map, Set, Date, RegExp, ArrayBuffer. Не копирует функции, DOM-элементы, символы в качестве ключей. Для большинства случаев на фронте - это то, что нужно.

<b class="text-on-semi-light">JSON.parse(JSON.stringify()):</b> Старый способ deep clone. Теряет `undefined`, `Function`, `Symbol`, `Date` (превращает в строку), `Map`, `Set`, `Infinity`, `NaN`. Не используй, когда доступен `structuredClone()`.

## Деструктуризация объектов

```js
const response = {
  data: {
    user: { name: "Alice", role: "admin" },
    token: "abc123",
  },
  status: 200,
};

// Базовая
const { status, data } = response;

// Переименование
const { status: httpStatus } = response;

// Значение по умолчанию
const { timeout = 3000 } = response;

// Вложенная
const { data: { user: { name, role } } } = response;

// Rest (собрать остальное)
const { status: s, ...rest } = response; // rest = { data: { ... } }

// В параметрах функции
function createUser({ name, role = "viewer", age = 18 }) {
  return { name, role, age };
}
createUser({ name: "Bob" }); // { name: "Bob", role: "viewer", age: 18 }
```

## Массивы

### Создание и доступ

```js
const arr = [1, 2, 3];
arr[0];           // 1
arr.at(-1);       // 3 (ES2022 - доступ с конца)
arr.length;       // 3

// Array.from - создание из итерируемого
Array.from("hello");           // ["h", "e", "l", "l", "o"]
Array.from({ length: 3 }, (_, i) => i); // [0, 1, 2]

// Array.of
Array.of(1, 2, 3); // [1, 2, 3]
```

## Методы массивов

### Мутирующие методы

Изменяют исходный массив и возвращают результат.

```js
const arr = [1, 2, 3];

arr.push(4);          // [1,2,3,4] - добавить в конец, вернёт длину
arr.pop();            // [1,2,3]   - удалить с конца, вернёт элемент
arr.unshift(0);       // [0,1,2,3] - добавить в начало
arr.shift();          // [1,2,3]   - удалить из начала

arr.splice(1, 1);     // [1,3]     - удалить 1 элемент с индекса 1
arr.splice(1, 0, 2);  // [1,2,3]   - вставить 2 на индекс 1

arr.sort((a, b) => a - b); // сортировка (мутирует!)
arr.reverse();              // реверс (мутирует!)
arr.fill(0, 1, 3);         // [1,0,0] - заполнить от индекса 1 до 3
```

### Немутирующие методы

Возвращают новый массив или значение, не изменяя оригинал.

```js
const nums = [1, 2, 3, 4, 5];

// Трансформация
nums.map((n) => n * 2);           // [2, 4, 6, 8, 10]
nums.filter((n) => n > 3);        // [4, 5]
nums.reduce((sum, n) => sum + n, 0); // 15

// Поиск
nums.find((n) => n > 3);          // 4 (первый подходящий)
nums.findIndex((n) => n > 3);     // 3 (индекс первого)
nums.findLast((n) => n > 3);      // 5 (ES2023 - последний подходящий)
nums.findLastIndex((n) => n > 3); // 4

// Проверка
nums.some((n) => n > 4);          // true (хотя бы один)
nums.every((n) => n > 0);         // true (все)
nums.includes(3);                 // true

// Без мутации
nums.slice(1, 3);                 // [2, 3] (от индекса 1 до 3, не включая)
nums.concat([6, 7]);              // [1,2,3,4,5,6,7]
nums.flat();                      // развернуть вложенные массивы
nums.flatMap((n) => [n, n * 2]);  // [1,2,2,4,3,6,4,8,5,10]
```

### Новые немутирующие копии (ES2023)

```js
const arr = [3, 1, 2];

arr.toSorted((a, b) => a - b);  // [1, 2, 3] - новый массив, arr не тронут
arr.toReversed();                // [2, 1, 3] - новый массив
arr.toSpliced(1, 1);            // [3, 2]    - новый массив
arr.with(0, 99);                // [99, 1, 2] - замена по индексу, новый массив
```

<b class="text-on-semi-light">На фронте:</b> `toSorted()`, `toReversed()`, `toSpliced()`, `with()` - идеальны для React/Vue, где нужны immutable-обновления state. Вместо `[...arr].sort()` пиши `arr.toSorted()`.

## Spread и деструктуризация массивов

```js
const arr = [1, 2, 3];

// Spread
const copy = [...arr];              // shallow copy
const merged = [...arr, 4, 5];     // [1,2,3,4,5]
Math.max(...arr);                   // 3

// Деструктуризация
const [first, second, ...rest] = arr; // first=1, second=2, rest=[3]
const [a, , c] = arr;                 // a=1, c=3 (пропуск элемента)

// Swap без временной переменной
let x = 1, y = 2;
[x, y] = [y, x]; // x=2, y=1
```

## Map

`Map` - коллекция пар ключ-значение, где ключом может быть **любое значение** (не только строка).

```js
const map = new Map();
map.set("name", "Alice");
map.set(42, "number key");
map.set(true, "boolean key");

const objKey = { id: 1 };
map.set(objKey, "object as key");

map.get("name");     // "Alice"
map.has(42);         // true
map.size;            // 4
map.delete(true);    // удалить по ключу
map.clear();         // очистить всё

// Итерация (порядок вставки гарантирован)
for (const [key, value] of map) {
  console.log(key, value);
}
```

### Map vs Object

| Характеристика          | Object                                | Map                           |
| ----------------------- | ------------------------------------- | ----------------------------- |
| Ключи                   | Строки и Symbol                       | Любое значение                |
| Порядок                 | Хронологический (с оговорками)        | Порядок вставки (гарантирован) |
| Размер                  | `Object.keys(obj).length`             | `map.size`                    |
| Итерация                | `for...in`, `Object.entries()`        | `for...of`, `.forEach()`     |
| Производительность      | Медленнее при частых add/delete       | Оптимизирован для add/delete  |
| Сериализация (JSON)     | Нативная                              | Нет (нужна конвертация)       |
| Прототип                | Есть (ключи из `Object.prototype`)    | Нет лишних ключей             |

<b class="text-on-semi-light">Когда Map:</b> Ключи не строки, частые добавления/удаления, нужен точный `.size`, нужна итерация в порядке вставки.

<b class="text-on-semi-light">Когда Object:</b> JSON-данные, конфиги, props компонентов, когда ключи - строки и структура статична.

## Set

`Set` - коллекция **уникальных** значений.

```js
const set = new Set([1, 2, 3, 3, 2]); // Set {1, 2, 3}
set.add(4);
set.has(3);    // true
set.delete(1);
set.size;      // 3

// Дедупликация массива
const unique = [...new Set([1, 1, 2, 2, 3])]; // [1, 2, 3]

// Итерация
for (const value of set) {
  console.log(value);
}
```

### Set operations (ES2025)

```js
const a = new Set([1, 2, 3, 4]);
const b = new Set([3, 4, 5, 6]);

a.union(b);             // Set {1, 2, 3, 4, 5, 6}
a.intersection(b);      // Set {3, 4}
a.difference(b);        // Set {1, 2}
a.symmetricDifference(b); // Set {1, 2, 5, 6}
a.isSubsetOf(b);        // false
a.isSupersetOf(b);      // false
a.isDisjointFrom(b);    // false
```

## WeakMap и WeakSet

«Слабые» коллекции, где ключи (WeakMap) или значения (WeakSet) - только объекты, и они **не мешают garbage collector** удалять объект, если на него больше нет других ссылок.

```js
const cache = new WeakMap();

function process(obj) {
  if (cache.has(obj)) return cache.get(obj);
  const result = /* тяжёлые вычисления */ obj.value * 2;
  cache.set(obj, result);
  return result;
}

let data = { value: 42 };
process(data); // вычислено и закэшировано
data = null;   // объект может быть собран GC, запись из WeakMap исчезнет автоматически
```

<b class="text-on-semi-light">Use cases WeakMap:</b>

- **Кэширование** - привязка вычислений к объекту без утечки памяти
- **Приватные данные** - хранение private-полей для объектов
- **Метаданные DOM-элементов** - привязка данных к элементу без data-атрибутов

<b class="text-on-semi-light">Ограничения:</b> WeakMap/WeakSet не итерируемы (нет `.forEach()`, `for...of`, `.size`). Это by design - GC может удалить элемент в любой момент, итерация была бы непредсказуемой.

## TypedArrays и ArrayBuffer

Для работы с бинарными данными: файлы, WebGL-текстуры, аудио, видео-стримы, WebSocket binary frames.

```js
// ArrayBuffer - блок сырой памяти (не читаемый напрямую)
const buffer = new ArrayBuffer(16); // 16 байт

// TypedArray - типизированное представление буфера
const view = new Uint8Array(buffer);   // 16 элементов по 1 байту
const ints = new Int32Array(buffer);   // 4 элемента по 4 байта

view[0] = 255;
ints[0]; // зависит от endianness

// DataView - гибкий доступ с контролем endianness
const dv = new DataView(buffer);
dv.setInt32(0, 42, true); // little-endian
```

<span class="text-gray">TypedArrays редко используются в повседневной фронтенд-разработке, но встречаются при работе с Canvas, WebGL, Web Audio API, FileReader и WebSocket binary. На собесе достаточно знать, что они существуют и зачем.</span>

## Циклы в JavaScript

| Цикл | Итерирует | break/continue | Использование |
|------|----------|---------------|--------------|
| `for` | По индексу | Да | Когда нужен счётчик |
| `while` | По условию | Да | Неизвестное число итераций |
| `do...while` | По условию (минимум 1 раз) | Да | Гарантированно выполнить 1 раз |
| `for...in` | Ключи объекта (enumerable, включая прототип) | Да | Свойства объектов (не массивов!) |
| `for...of` | Значения iterable (Array, String, Map, Set) | Да | Массивы и коллекции |
| `forEach` | Элементы массива | Нет | Простой перебор без прерывания |
| `map` | Элементы -> новый массив | Нет | Трансформация |
| `filter` | Элементы -> отфильтрованный массив | Нет | Фильтрация |
| `reduce` | Элементы -> одно значение | Нет | Аккумуляция |

<b class="text-on-semi-light">Какой цикл выбрать?</b>

- Нужен индекс -> `for`
- Перебор массива -> `for...of` или `forEach`
- Перебор свойств объекта -> `for...in` (или `Object.entries()` + `for...of`)
- Трансформация данных -> `map`, `filter`, `reduce`
- Нужно прервать -> `for`, `for...of`, `while` (в `forEach` нельзя `break`)

⚠️ Не используй `for...in` для массивов - он итерирует строковые ключи, включая унаследованные свойства, и порядок не гарантирован.

## Паттерны работы с массивами

<b class="text-on-semi-light">Вставка элемента</b>

```js
// Мутирующий: splice
const arr = [1, 2, 4, 5];
arr.splice(2, 0, 3); // [1, 2, 3, 4, 5]

// Иммутабельный: spread + slice
const newArr = [...arr.slice(0, 2), 3, ...arr.slice(2)];

// ES2023: toSpliced (не мутирует!)
const newArr2 = arr.toSpliced(2, 0, 3);
```

<b class="text-on-semi-light">Изменение элемента</b>

```js
// Мутирующий: splice
arr.splice(2, 1, 99); // Заменить элемент на индексе 2

// Иммутабельный: map
const updated = arr.map(x => x === 3 ? 99 : x);

// ES2023: with (не мутирует!)
const updated2 = arr.with(2, 99);
```

<b class="text-on-semi-light">Удаление элемента</b>

```js
// Мутирующий: splice
arr.splice(2, 1);

// Иммутабельный: filter
const without3 = arr.filter(x => x !== 3);

// ES2023: toSpliced
const without = arr.toSpliced(2, 1);
```

| Метод | Мутирует? | Подходит для |
|-------|----------|-------------|
| `splice()` | Да | Прямая модификация |
| `map()` / `filter()` | Нет | React/Vue (иммутабельный state) |
| `toSpliced()` / `with()` (ES2023) | Нет | Современный иммутабельный подход |

## Дополнительные методы объектов

<b class="text-on-semi-light">Проверка свойств</b>

```js
const user = { name: 'Alice' };

// hasOwnProperty - только собственные свойства
user.hasOwnProperty('name')     // true
user.hasOwnProperty('toString') // false

// in - включая прототип
'name' in user      // true
'toString' in user  // true (из Object.prototype)

// Object.hasOwn() (ES2022) - рекомендуемый способ
Object.hasOwn(user, 'name')     // true
Object.hasOwn(user, 'toString') // false
```

<b class="text-on-semi-light">Защита объектов: сравнение</b>

| Метод | Добавление | Изменение | Удаление |
|-------|-----------|-----------|----------|
| `Object.preventExtensions()` | Нет | Да | Да |
| `Object.seal()` | Нет | Да | Нет |
| `Object.freeze()` | Нет | Нет | Нет |

Проверки: `Object.isExtensible()`, `Object.isSealed()`, `Object.isFrozen()`

> `Object.freeze()` - shallow. Вложенные объекты остаются мутабельными. Для deep freeze нужна рекурсия или `structuredClone()` + `Object.freeze()`.

## Частые вопросы на собесе

**Чем отличается shallow copy от deep copy?**
Shallow copy копирует только первый уровень. Вложенные объекты остаются ссылками на оригинал. Deep copy рекурсивно копирует все уровни. Shallow: spread `{...obj}`, `Object.assign()`. Deep: `structuredClone()` (ES2022). `JSON.parse(JSON.stringify())` - ненадёжен (теряет `undefined`, `Date`, `Map`, функции).

**Какие методы массивов мутируют, какие нет?**
Мутирующие: `push`, `pop`, `shift`, `unshift`, `splice`, `sort`, `reverse`, `fill`. Немутирующие: `map`, `filter`, `reduce`, `slice`, `concat`, `flat`, `flatMap`, `find`, `every`, `some`. ES2023 добавил немутирующие аналоги: `toSorted()`, `toReversed()`, `toSpliced()`, `with()`.

**Когда использовать Map вместо Object?**
Когда ключи не строки, нужен точный `.size`, частые добавления/удаления, гарантированный порядок итерации. Object - для JSON-данных, конфигов, props.

**Что такое WeakMap и зачем он нужен?**
Map, где ключи - только объекты, и они «слабо» удерживаются. Если объект-ключ больше нигде не используется, GC может его удалить вместе с записью из WeakMap. Используется для кэширования и хранения метаданных без утечек памяти.

**Как работает деструктуризация с вложенными объектами?**
`const { data: { user: { name } } } = response` - каждый уровень разворачивается через `{ key: { nested } }`. Можно задавать значения по умолчанию: `{ name = "Anon" }` и переименовывать: `{ name: userName }`.
