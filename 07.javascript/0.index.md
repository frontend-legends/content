# JavaScript

**JavaScript** - это язык, на котором строится интерактивный веб. Это не просто «скриптик для кнопок» - это высокоуровневый, мультипарадигменный язык с собственной моделью памяти, событийным циклом, прототипным наследованием и одним из самых мощных runtime-окружений в индустрии. Глубокое понимание JS - основа любого frontend-собеседования.

---

## Зачем это нужно на собесе

JavaScript - главный язык фронтенда. На техническом интервью проверяют не умение писать `console.log`, а понимание того, **как и почему** язык работает именно так:

- объяснить разницу между **примитивами и ссылочными типами**, и что происходит при копировании объекта;
- понимать **замыкания, контекст и прототипное наследование** на уровне механики;
- знать, как работает **Event Loop**, microtasks и macrotasks;
- уверенно работать с **асинхронностью**: Promises, async/await, race conditions;
- разбираться в **модульной системе**: ESM vs CommonJS, tree-shaking;
- писать чистый, идиоматичный код с использованием **современного синтаксиса** ES2015+.

---

## Что даёт глубокое знание JavaScript

- Пишешь **предсказуемый код**, потому что понимаешь type coercion, hoisting и scoping.
- Отлаживаешь баги **быстрее**, потому что знаешь, как работает движок под капотом.
- Принимаешь **архитектурные решения** осознанно: паттерны, модули, обработка ошибок.
- Легко **осваиваешь фреймворки**, потому что React, Vue, Angular - это надстройки над JS.
- Уверенно **проходишь live-coding**, потому что знаешь тонкости языка.

> Как браузер парсит и выполняет JS, подробно разобрано в [Как выполняется код](/content/computer-science/running-the-code).

В этом разделе - 16 тем, от основ языка до продвинутых паттернов:

1. **Введение в JavaScript** - характеристики языка, история, ECMAScript, среды выполнения
2. **Типы данных и переменные** - примитивы, ссылочные типы, var/let/const, coercion, TDZ

4. **Функции** - объявление, стрелочные функции, замыкания, параметры, IIFE, каррирование

6. **Прототипы и классы** - прототипная цепочка, [[Prototype]], классы ES6, наследование
7. **Область видимости и замыкания** - scope chain, lexical environment, closures на практике
8. **Обработка ошибок** - try/catch/finally, типы ошибок, custom errors, async error handling
9. **Асинхронность** - Event Loop, callbacks, Promises, async/await, microtasks, macrotasks
10. **Модули** - ESM, CommonJS, динамический import, tree-shaking, циклические зависимости
11. **Итераторы и генераторы** - Symbol.iterator, протоколы, function*, yield, async generators
12. **Proxy и Reflect** - перехват операций, мета-программирование, use cases
13. **Работа с DOM** - DOM API, события, делегирование, MutationObserver, виртуальный DOM
14. **Хранение данных** - localStorage, sessionStorage, IndexedDB, cookies, Cache API
15. **Web API** - Fetch, AbortController, WebSocket, Workers, Intersection Observer
16. **Паттерны и лучшие практики** - чистый код, оптимизация, debounce/throttle, immutability
