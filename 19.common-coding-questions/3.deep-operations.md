# Глубокие операции с данными

Вторая по частоте группа задач - **рекурсивная работа со вложенными структурами**: `deepClone`, `deepEqual`, `flatten`, доступ по пути (`get`/`set`). Проверяют рекурсию, обработку типов и краевые случаи (циклы, `null`, массивы vs объекты).

---

## deepClone

<b class="text-on-semi-light">Глубокое клонирование</b> <span class="text-gray">- создание полной копии объекта, где вложенные объекты тоже скопированы, а не разделены по ссылке. Мутация копии не должна затрагивать оригинал.</span>

**Простой вариант (то, с чего начать):**

```ts
const clone = structuredClone(original); // встроенный, since 2022
// или старый трюк (с оговорками):
const clone2 = JSON.parse(JSON.stringify(original));
```

> ⚠️ `JSON.parse(JSON.stringify(...))` теряет `undefined`, функции, `Date` (станет строкой), `Map`/`Set`, падает на циклах. На собесе это нужно **назвать** - и потом написать рекурсию руками.

**Рекурсивная реализация (то, что хотят увидеть):**

```ts
function deepClone<T>(value: T, seen = new WeakMap()): T {
  // примитивы и функции возвращаем как есть
  if (value === null || typeof value !== "object") return value;

  // защита от циклических ссылок
  if (seen.has(value)) return seen.get(value);

  if (value instanceof Date) return new Date(value) as T;
  if (value instanceof RegExp) return new RegExp(value) as T;

  if (Array.isArray(value)) {
    const arr: any[] = [];
    seen.set(value, arr);
    value.forEach((item, i) => (arr[i] = deepClone(item, seen)));
    return arr as T;
  }

  if (value instanceof Map) {
    const map = new Map();
    seen.set(value, map);
    value.forEach((v, k) => map.set(k, deepClone(v, seen)));
    return map as T;
  }

  const result: Record<string, any> = {};
  seen.set(value, result); // записываем ДО рекурсии - иначе цикл зациклит
  for (const key of Object.keys(value)) {
    result[key] = deepClone((value as any)[key], seen);
  }
  return result as T;
}
```

**Ключевые моменты:**

1. **Базовый случай** - примитивы и `null` возвращаем как есть.
2. **Циклы** - `WeakMap` запоминает уже клонированные объекты. Записывать в него надо **до** рекурсии.
3. **Особые типы** - `Date`, `RegExp`, `Map`, `Set` требуют отдельной обработки.

## deepEqual

<b class="text-on-semi-light">Глубокое сравнение</b> <span class="text-gray">- проверка, что две структуры равны по значению на всех уровнях, а не по ссылке.</span>

```ts
function deepEqual(a: unknown, b: unknown): boolean {
  if (a === b) return true; // примитивы и одна ссылка (учитывает +0/-0 неточно, но ок)

  if (typeof a !== "object" || typeof b !== "object" || a === null || b === null) {
    return false;
  }

  const keysA = Object.keys(a as object);
  const keysB = Object.keys(b as object);
  if (keysA.length !== keysB.length) return false;

  return keysA.every(
    (key) =>
      Object.prototype.hasOwnProperty.call(b, key) &&
      deepEqual((a as any)[key], (b as any)[key])
  );
}
```

> Уточняющие вопросы: как сравнивать массивы (тоже `Object.keys` сработает по индексам)? Что с `NaN` (`NaN !== NaN`)? Нужен ли учёт `Date`/`Map`? Хорошо проговорить ограничения.

## flatten массива

<b class="text-on-semi-light">flatten</b> <span class="text-gray">- превращает вложенный массив в плоский. Классика - с параметром глубины (`depth`), как `Array.prototype.flat`.</span>

```ts
function flatten<T>(arr: any[], depth = Infinity): T[] {
  return arr.reduce<T[]>((acc, item) => {
    if (Array.isArray(item) && depth > 0) {
      acc.push(...flatten<T>(item, depth - 1));
    } else {
      acc.push(item);
    }
    return acc;
  }, []);
}

flatten([1, [2, [3, [4]]]]);    // [1, 2, 3, 4]
flatten([1, [2, [3]]], 1);      // [1, 2, [3]]
```

**Итеративный вариант через стек** (если просят без рекурсии - защита от переполнения стека):

```ts
function flattenIter(arr: any[]): any[] {
  const stack = [...arr];
  const result: any[] = [];
  while (stack.length) {
    const next = stack.pop();
    if (Array.isArray(next)) stack.push(...next);
    else result.push(next);
  }
  return result.reverse(); // pop разворачивает порядок
}
```

## flatten объекта

<b class="text-on-semi-light">flattenObject</b> <span class="text-gray">- превращает вложенный объект в плоский, где ключи - это пути через точку. Частая задача под конфиги/формы.</span>

```ts
function flattenObject(obj: Record<string, any>, prefix = ""): Record<string, any> {
  const result: Record<string, any> = {};

  for (const key of Object.keys(obj)) {
    const path = prefix ? `${prefix}.${key}` : key;
    const value = obj[key];

    if (value && typeof value === "object" && !Array.isArray(value)) {
      Object.assign(result, flattenObject(value, path));
    } else {
      result[path] = value;
    }
  }
  return result;
}

flattenObject({ a: { b: { c: 1 } }, d: 2 }); // { "a.b.c": 1, d: 2 }
```

## get / set по пути (lodash-style)

<b class="text-on-semi-light">get(obj, path)</b> <span class="text-gray">- безопасно достаёт значение по пути (`"a.b[0].c"`), возвращая `default`, если путь не существует. `set` - наоборот, создаёт путь.</span>

```ts
function get(obj: any, path: string | string[], def?: unknown) {
  const keys = Array.isArray(path)
    ? path
    : path.replace(/\[(\w+)\]/g, ".$1").split(".").filter(Boolean);

  let result = obj;
  for (const key of keys) {
    if (result == null) return def;
    result = result[key];
  }
  return result === undefined ? def : result;
}

function set(obj: any, path: string, value: unknown) {
  const keys = path.replace(/\[(\w+)\]/g, ".$1").split(".").filter(Boolean);
  let curr = obj;

  keys.forEach((key, i) => {
    if (i === keys.length - 1) {
      curr[key] = value;
    } else {
      // создаём недостающий уровень: массив если следующий ключ числовой
      if (curr[key] == null) curr[key] = /^\d+$/.test(keys[i + 1]) ? [] : {};
      curr = curr[key];
    }
  });
  return obj;
}

get({ a: { b: [{ c: 42 }] } }, "a.b[0].c"); // 42
get({ a: 1 }, "a.b.c", "default");          // "default" (не падает)
```

> Оптимальный чейнинг `?.` решает чтение, но `get` нужен для **динамических путей-строк** (из конфига, формы) - там оператор не поможет.

## Вопросы на собеседовании

<b class="text-on-semi-light">Чем плох JSON.parse(JSON.stringify()) для клонирования?</b>
<span class="text-gray">Теряет `undefined`, функции и `Symbol`, превращает `Date` в строку, не умеет `Map`/`Set`, падает на циклических ссылках. Годится для простых JSON-данных, не для произвольных объектов.</span>

<b class="text-on-semi-light">Как обработать циклические ссылки в deepClone?</b>
<span class="text-gray">Через `WeakMap`, который сопоставляет оригинал уже созданной копии. Записывать в него надо до рекурсивного обхода - тогда повторная встреча того же объекта вернёт готовую копию вместо зацикливания.</span>

<b class="text-on-semi-light">Почему именно WeakMap, а не Map?</b>
<span class="text-gray">`WeakMap` держит ключи слабо - после клонирования объекты могут быть собраны сборщиком мусора, память не течёт. И ключами могут быть только объекты, что нам и нужно.</span>

<b class="text-on-semi-light">Как реализовать flatten без рекурсии?</b>
<span class="text-gray">Через стек: кладём элементы, `pop`, если массив - разворачиваем обратно в стек, иначе в результат. Защищает от переполнения стека на очень глубоких структурах. Порядок в конце развернуть.</span>

<b class="text-on-semi-light">Зачем нужен lodash `get`, если есть оператор `?.`?</b>
<span class="text-gray">`?.` работает со статическими путями в коде. `get` принимает путь строкой/массивом - для динамических путей из конфига, схемы формы, URL. Плюс единый `default`.</span>
