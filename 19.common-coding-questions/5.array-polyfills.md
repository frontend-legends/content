# Полифилы методов массива

«Реализуй `map`/`reduce`/`filter` без использования встроенных», «напиши `Array.flat`», «сделай `groupBy`» - проверяют понимание **колбэков, аккумуляторов, краевых случаев** (`thisArg`, разреженные массивы, начальное значение `reduce`).

---

## map

<b class="text-on-semi-light">map</b> <span class="text-gray">- создаёт новый массив, применяя колбэк к каждому элементу. Не мутирует исходный.</span>

```ts
Array.prototype.myMap = function <U>(
  callback: (value: any, index: number, array: any[]) => U,
  thisArg?: unknown
): U[] {
  const result: U[] = [];
  for (let i = 0; i < this.length; i++) {
    if (i in this) {                              // пропускаем «дыры» (разреженный массив)
      result[i] = callback.call(thisArg, this[i], i, this);
    }
  }
  return result;
};
```

**На что смотрят:**

1. **Три аргумента колбэка** - `value, index, array` (не только value).
2. **`thisArg`** - через `callback.call(thisArg, ...)`.
3. **Новый массив** - не мутируем `this`.
4. **Разреженные массивы** - `i in this` пропускает пустые ячейки (необязательно, но показывает глубину).

## filter

```ts
Array.prototype.myFilter = function (
  predicate: (value: any, index: number, array: any[]) => boolean,
  thisArg?: unknown
) {
  const result: any[] = [];
  for (let i = 0; i < this.length; i++) {
    if (i in this && predicate.call(thisArg, this[i], i, this)) {
      result.push(this[i]);
    }
  }
  return result;
};
```

## reduce

<b class="text-on-semi-light">reduce</b> <span class="text-gray">- сворачивает массив в одно значение, прокидывая аккумулятор. Самый каверзный из-за **необязательного начального значения**.</span>

```ts
Array.prototype.myReduce = function <T>(
  callback: (acc: T, value: any, index: number, array: any[]) => T,
  initial?: T
): T {
  let acc: T;
  let startIndex: number;

  if (arguments.length >= 2) {
    acc = initial as T;
    startIndex = 0;
  } else {
    // без initial: первый элемент становится аккумулятором
    if (this.length === 0) {
      throw new TypeError("Reduce of empty array with no initial value");
    }
    acc = this[0];
    startIndex = 1;
  }

  for (let i = startIndex; i < this.length; i++) {
    if (i in this) acc = callback(acc, this[i], i, this);
  }
  return acc;
};
```

> ⚠️ Главная ловушка: проверять наличие `initial` через `arguments.length >= 2`, а не `if (initial)`. Иначе `reduce(fn, 0)` или `reduce(fn, undefined)` сломаются. И пустой массив без начального значения должен **бросить TypeError** - как нативный.

## forEach

```ts
Array.prototype.myForEach = function (
  callback: (value: any, index: number, array: any[]) => void,
  thisArg?: unknown
): void {
  for (let i = 0; i < this.length; i++) {
    if (i in this) callback.call(thisArg, this[i], i, this);
  }
  // ничего не возвращает - undefined
};
```

`map` через `reduce` - частый дополнительный вопрос «реализуй одно через другое»:

```ts
const map = <T, U>(arr: T[], fn: (x: T) => U): U[] =>
  arr.reduce<U[]>((acc, x) => [...acc, fn(x)], []);
```

## Array.flat

Полифил `flat` с глубиной (рекурсивно, как в [глубоких операциях](/content/common-coding-questions/deep-operations)):

```ts
Array.prototype.myFlat = function (depth = 1): any[] {
  const result: any[] = [];
  for (const item of this) {
    if (Array.isArray(item) && depth > 0) {
      result.push(...item.myFlat(depth - 1));
    } else {
      result.push(item);
    }
  }
  return result;
};
```

## groupBy

<b class="text-on-semi-light">groupBy</b> <span class="text-gray">- группирует элементы массива по ключу, который возвращает функция. Очень частая «продуктовая» задача.</span>

```ts
function groupBy<T>(arr: T[], keyFn: (item: T) => string | number) {
  return arr.reduce<Record<string, T[]>>((acc, item) => {
    const key = keyFn(item);
    (acc[key] ??= []).push(item);  // создаём массив, если ключа ещё нет
    return acc;
  }, {});
}

groupBy([6.1, 4.2, 6.3], Math.floor);
// { 4: [4.2], 6: [6.1, 6.3] }
```

`??=` (логическое присваивание) изящно создаёт массив только при первом ключе.

## unique (дедупликация)

```ts
// примитивы - через Set
const unique = <T>(arr: T[]): T[] => [...new Set(arr)];

// объекты по ключу - через Map (сохраняет первый/последний)
function uniqueBy<T>(arr: T[], keyFn: (item: T) => unknown): T[] {
  const map = new Map();
  for (const item of arr) {
    const key = keyFn(item);
    if (!map.has(key)) map.set(key, item);
  }
  return [...map.values()];
}
```

> Уточняющий вопрос: «уникальность примитивов или объектов?» Для примитивов хватит `Set`, для объектов нужен ключ - `Set` сравнивает объекты по ссылке.

## Вопросы на собеседовании

<b class="text-on-semi-light">Какие аргументы получает колбэк map/filter/reduce?</b>
<span class="text-gray">map/filter/forEach: `(value, index, array)`. reduce: `(accumulator, value, index, array)`. Многие забывают про index и array - интервьюер это проверяет.</span>

<b class="text-on-semi-light">Как в reduce корректно обработать необязательное начальное значение?</b>
<span class="text-gray">Проверять `arguments.length >= 2`, а не «истинность» initial. Иначе `reduce(fn, 0)` сломается. Если initial нет - аккумулятором становится первый элемент, обход с индекса 1; пустой массив без initial бросает TypeError.</span>

<b class="text-on-semi-light">Что такое thisArg и зачем он?</b>
<span class="text-gray">Второй аргумент `map`/`filter`/`forEach` - значение `this` внутри колбэка. Реализуется через `callback.call(thisArg, ...)`. Со стрелочными колбэками бесполезен.</span>

<b class="text-on-semi-light">Как сделать map через reduce?</b>
<span class="text-gray">`arr.reduce((acc, x) => [...acc, fn(x)], [])`. Показывает, что reduce - универсальный примитив, через который выражаются map/filter. (В проде так не пишут - O(n²) из-за спреда.)</span>

<b class="text-on-semi-light">Как дедуплицировать массив объектов?</b>
<span class="text-gray">`Set` не подойдёт - он сравнивает объекты по ссылке. Нужен `Map` по вычисленному ключу (id, или сериализация), беря первый встреченный элемент на ключ.</span>
