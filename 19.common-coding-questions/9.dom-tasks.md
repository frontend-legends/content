# Задачи на DOM

Фронтендера проверяют на знании **живого DOM**: делегирование событий, обход дерева, собственные реализации `querySelector`/`getElementsByClassName`, утилиты вроде `classNames`. Это то, что отличает «писал только в React» от «понимаю платформу».

---

## Делегирование событий

<b class="text-on-semi-light">Делегирование</b> <span class="text-gray">- вешаем один обработчик на родителя вместо обработчика на каждый дочерний элемент. Работает за счёт **всплытия** событий. Экономит память и работает для динамически добавленных элементов.</span>

```ts
function delegate(
  parent: HTMLElement,
  eventType: string,
  selector: string,
  handler: (event: Event, target: Element) => void
) {
  parent.addEventListener(eventType, (event) => {
    // ищем ближайший подходящий элемент вверх от точки клика
    const target = (event.target as Element).closest(selector);
    if (target && parent.contains(target)) {
      handler(event, target);
    }
  });
}

// один обработчик на весь список, даже для будущих <li>
delegate(document.querySelector("ul")!, "click", "li", (e, li) => {
  console.log("clicked", li.textContent);
});
```

**Зачем это любят спрашивать:**

1. **Всплытие** - событие идёт от target вверх к родителям, поэтому родитель его «слышит».
2. **`closest`** - поднимается от `event.target` до подходящего селектора (клик мог попасть в `<span>` внутри `<li>`).
3. **Динамика** - новые элементы работают без перевешивания обработчиков.

> Уточняющий вопрос: «а что, если событие не всплывает?» (`focus`, `blur`, `mouseenter`) - тогда делегирование через `addEventListener(..., true)` на фазе capture или замена на всплывающий аналог (`focusin`).

## Свой getElementsByClassName

Проверяет понимание обхода дерева:

```ts
function getElementsByClassName(root: Element, className: string): Element[] {
  const result: Element[] = [];

  function traverse(node: Element) {
    if (node.classList.contains(className)) result.push(node);
    // children - только элементы (без текстовых узлов)
    for (const child of node.children) traverse(child);
  }

  traverse(root);
  return result;
}
```

Это обычный **DFS по дереву DOM**. Хороший момент - проговорить разницу `children` (элементы) vs `childNodes` (включая текст и комментарии).

## Обход дерева DOM

<b class="text-on-semi-light">Обход DOM</b> <span class="text-gray">- частая задача: посчитать узлы, найти максимальную глубину, собрать все теги. И DFS (рекурсия/стек), и BFS (очередь) - оба должны быть в голове.</span>

```ts
// DFS - глубина
function maxDepth(node: Element): number {
  if (node.children.length === 0) return 1;
  return 1 + Math.max(...[...node.children].map(maxDepth));
}

// BFS - по уровням
function bfs(root: Element): Element[] {
  const queue: Element[] = [root];
  const visited: Element[] = [];
  while (queue.length) {
    const node = queue.shift()!;
    visited.push(node);
    queue.push(...node.children);
  }
  return visited;
}
```

Браузерный API для этого - `TreeWalker` / `NodeIterator`, стоит упомянуть, что в проде есть встроенный обход.

## classNames (утилита cn)

<b class="text-on-semi-light">classNames</b> <span class="text-gray">- собирает строку классов из строк, объектов и массивов, отбрасывая falsy. Та самая `cn`/`clsx`, что во всех React-проектах.</span>

```ts
type ClassValue = string | number | null | undefined | false | ClassDict | ClassValue[];
interface ClassDict { [key: string]: boolean | undefined | null; }

function classNames(...args: ClassValue[]): string {
  const classes: string[] = [];

  for (const arg of args) {
    if (!arg) continue;                          // falsy пропускаем

    if (typeof arg === "string" || typeof arg === "number") {
      classes.push(String(arg));
    } else if (Array.isArray(arg)) {
      const inner = classNames(...arg);          // рекурсия для массивов
      if (inner) classes.push(inner);
    } else if (typeof arg === "object") {
      for (const key in arg) {
        if (arg[key]) classes.push(key);         // ключ включается, если значение truthy
      }
    }
  }
  return classes.join(" ");
}

classNames("btn", { active: true, disabled: false }, ["lg", null]);
// "btn active lg"
```

## Свой querySelector (упрощённый)

Иногда просят разобрать строку селектора и найти узлы - проверка парсинга + обхода:

```ts
function querySelectorByTag(root: Element, tag: string): Element[] {
  const result: Element[] = [];
  function walk(node: Element) {
    if (node.tagName.toLowerCase() === tag.toLowerCase()) result.push(node);
    for (const child of node.children) walk(child);
  }
  walk(root);
  return result;
}
```

> Полный CSS-селектор парсить на собесе не просят - достаточно по тегу/классу/id и проговорить, что настоящий парсер разбирает комбинаторы (`>`, ` `, `+`), псевдоклассы и т.д.

## Вопросы на собеседовании

<b class="text-on-semi-light">Что такое делегирование событий и зачем оно?</b>
<span class="text-gray">Один обработчик на родителе вместо обработчика на каждом потомке - работает благодаря всплытию. Экономит память, автоматически покрывает динамически добавленные элементы. Внутри используем `event.target.closest(selector)`.</span>

<b class="text-on-semi-light">Чем children отличается от childNodes?</b>
<span class="text-gray">`children` - только узлы-элементы (`Element`). `childNodes` - все узлы, включая текстовые и комментарии. Для обхода дерева элементов нужен `children`, иначе зацепишь пробелы и переносы строк.</span>

<b class="text-on-semi-light">Что делать, если событие не всплывает (focus/blur)?</b>
<span class="text-gray">Использовать фазу capture (`addEventListener(type, handler, true)`) или всплывающие аналоги: `focusin`/`focusout` вместо `focus`/`blur`. mouseenter/leave заменяют на mouseover/out с проверкой target.</span>

<b class="text-on-semi-light">Как обойти всё DOM-дерево?</b>
<span class="text-gray">DFS - рекурсией или стеком по `children`; BFS - очередью по уровням. Встроенный способ - `TreeWalker`/`NodeIterator`. Важно помнить про разницу children/childNodes.</span>

<b class="text-on-semi-light">Как работает утилита classNames/clsx?</b>
<span class="text-gray">Принимает строки, объекты `{класс: boolean}` и массивы, рекурсивно их разбирает, отбрасывает falsy и склеивает оставшиеся классы через пробел. Для объектов класс попадает в результат, если его значение truthy.</span>
