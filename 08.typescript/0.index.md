# TypeScript

**TypeScript** - это надстройка (superset) над JavaScript, добавляющая статическую типизацию. Типы проверяются на этапе компиляции и полностью удаляются в runtime - в браузер попадает обычный JS. На собеседованиях TypeScript - это вопросы о системе типов, дженериках, utility types, сужении типов и типизации React/Vue компонентов.

---

## Зачем это нужно

- Ошибки ловятся **до запуска** - не в production, а в IDE
- Автодополнение и рефакторинг работают **точно**, а не по угадыванию
- Типы - это **документация**, которая всегда актуальна
- Вопросы по TS - обязательная часть интервью на любую frontend-позицию

---

## Что здесь есть

- Введение: зачем TS, как работает, type inference vs annotations
- Базовые типы: примитивы, any/unknown/never, enum, literal, as const, satisfies
- Функции и классы: типизация параметров, overloads, abstract, decorators
- Композиция типов: union, intersection, type vs interface, keyof, typeof
- Сужение типов: type guards, discriminated unions, exhaustive checking
- Дженерики: constraints, defaults, keyof patterns
- Utility types: Partial, Pick, Omit, Record, ReturnType и др.
- Продвинутые типы: mapped, conditional, infer, template literals, branded types
- Настройка проекта: tsconfig.json, strict mode, .d.ts, DefinitelyTyped
- Async и DOM: типизация промисов, DOM events, API-клиент
- TS + React: props, hooks, events, generic components
- TS + Vue: defineProps, defineEmits, composables
