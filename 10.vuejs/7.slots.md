# Слоты

**Слоты** - механизм передать разметку **внутрь** компонента. Это Vue-аналог `children` и render props в React. Слоты делают компоненты по-настоящему переиспользуемыми: контейнер задаёт структуру, а содержимое подставляет потребитель.

---

## Дефолтный слот

`<slot>` в шаблоне компонента - место, куда вставится переданная разметка.

```vue
<!-- Card.vue -->
<template>
  <div class="card">
    <slot></slot> <!-- сюда попадёт содержимое -->
  </div>
</template>
```

```vue
<!-- использование -->
<Card>
  <h3>Заголовок</h3>
  <p>Текст</p>
</Card>
```

Всё между тегами `<Card>...</Card>` подставится на место `<slot>`. Это прямой аналог `props.children`.

### Запасное содержимое

Внутри `<slot>` можно задать контент по умолчанию - покажется, если потребитель ничего не передал.

```vue
<slot>Нет данных</slot> <!-- fallback, если слот пуст -->
```

---

## Именованные слоты

Когда «дырок» несколько, им дают имена.

```vue
<!-- Layout.vue -->
<template>
  <header><slot name="header" /></header>
  <main><slot /></main>            <!-- дефолтный (без имени) -->
  <footer><slot name="footer" /></footer>
</template>
```

```vue
<!-- использование: v-slot:name или сокращение #name -->
<Layout>
  <template #header><h1>Шапка</h1></template>

  <p>Основной контент идёт в дефолтный слот</p>

  <template #footer><small>Подвал</small></template>
</Layout>
```

---

## Scoped slots - данные из компонента в слот

Самая мощная и «собеседная» часть. **Scoped slot** позволяет компоненту **передать данные наверх в содержимое слота**. Контейнер владеет данными/логикой, а как их отрисовать - решает потребитель.

```vue
<!-- UserList.vue -->
<template>
  <ul>
    <li v-for="user in users" :key="user.id">
      <slot :user="user" :index="user.id" /> <!-- отдаём user в слот -->
    </li>
  </ul>
</template>
```

```vue
<!-- потребитель решает, КАК отрисовать каждый user -->
<UserList :users="users">
  <template #default="{ user }">
    <strong>{{ user.name }}</strong> — {{ user.email }}
  </template>
</UserList>
```

<b class="text-on-semi-light">Зачем это нужно</b> - <span class="text-gray">Компонент инкапсулирует логику (итерация, загрузка, состояние), но **не диктует разметку**. Потребитель получает данные через слот-пропсы и рендерит как хочет. Это Vue-аналог render props в React.</span>

---

## Renderless-компоненты

Логика без собственной разметки: компонент только готовит данные и отдаёт их через scoped slot, ничего не рисуя сам.

```vue
<!-- MouseTracker.vue - только логика -->
<script setup>
import { ref } from 'vue';
const x = ref(0), y = ref(0);
function move(e) { x.value = e.clientX; y.value = e.clientY; }
</script>

<template>
  <div @mousemove="move"><slot :x="x" :y="y" /></div>
</template>
```

```vue
<MouseTracker #default="{ x, y }">Курсор: {{ x }}, {{ y }}</MouseTracker>
```

> В Vue 3 renderless-компоненты во многом вытеснены [composables](/content/vuejs/composables) - чистую логику проще переиспользовать функцией, чем компонентом. Но для логики, **завязанной на разметку/слот**, паттерн остаётся актуальным.

---

## Динамические имена слотов

```vue
<template #[dynamicName]>...</template>
```

Имя слота можно вычислять - полезно для конфигурируемых layout'ов.

---

## Слоты vs React

| Vue | React-аналог |
|-----|--------------|
| дефолтный `<slot>` | `props.children` |
| именованные слоты | props-слоты (`header={<.../>}`) |
| scoped slots | render props / children-as-function |
| renderless-компонент | render-props-компонент |

<b class="text-on-semi-light">Отличие</b> - <span class="text-gray">В React всё это - просто функции и узлы в props. Во Vue слоты - отдельная сущность с собственным синтаксисом (`#name`, `v-slot`), которую компилятор оптимизирует. Концептуально - то же самое.</span>

## Вопросы на собеседовании

<b class="text-on-semi-light">Что такое слоты и зачем они нужны?</b>
<span class="text-gray">Механизм передать разметку внутрь компонента. Контейнер задаёт структуру, потребитель - содержимое. Аналог `children` в React.</span>

<b class="text-on-semi-light">Чем именованные слоты отличаются от дефолтного?</b>
<span class="text-gray">Дефолтный слот один и безымянный; именованные позволяют несколько точек вставки (`#header`, `#footer`).</span>

<b class="text-on-semi-light">Что такое scoped slots?</b>
<span class="text-gray">Слоты, в которые компонент передаёт данные (слот-пропсы), а потребитель решает, как их отрисовать. Vue-аналог render props.</span>

<b class="text-on-semi-light">Что такое renderless-компонент?</b>
<span class="text-gray">Компонент без собственной разметки: только готовит данные/логику и отдаёт через scoped slot. В Vue 3 часто заменяется composables.</span>

<b class="text-on-semi-light">Как соотносятся слоты Vue и паттерны React?</b>
<span class="text-gray">Дефолтный слот ≈ children, именованные ≈ props-слоты, scoped slots ≈ render props. Концепция та же, у Vue - отдельный синтаксис и оптимизация компилятором.</span>
