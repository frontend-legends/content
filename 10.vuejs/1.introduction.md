# Введение в Vue

**Vue** - фреймворк для построения пользовательских интерфейсов, созданный Эваном Ю (Evan You) в 2014 году. Как и React, он декларативный и компонентный: ты описываешь, как UI должен выглядеть при текущем состоянии, а Vue синхронизирует с ним DOM. Ключевое отличие - **система реактивности**: Vue автоматически отслеживает зависимости и обновляет только то, что реально изменилось.

> «Прогрессивный фреймворк» - Vue можно подключить одним скриптом к существующей странице, а можно строить на нём полноценное SPA с роутингом, стором и SSR. Ты берёшь ровно столько, сколько нужно.

---

## Декларативность и реактивность

```vue
<script setup>
import { ref } from 'vue';
const count = ref(0);
</script>

<template>
  <button @click="count++">{{ count }}</button>
</template>
```

Ты не пишешь «найди кнопку и обнови текст». Ты объявляешь реактивное состояние `count` и привязываешь его к шаблону. Vue **сам** знает, что `{{ count }}` зависит от `count`, и обновит именно этот текстовый узел при изменении.

<b class="text-on-semi-light">В этом суть Vue</b> - <span class="text-gray">Реактивность связывает данные и DOM автоматически. Не нужно ни вручную обновлять узлы (как в vanilla), ни заботиться о том, что перерисуется (как с мемоизацией в React) - зависимости отслеживаются на лету.</span>

## Single-File Components

Канонический формат Vue - **SFC** (`.vue`): шаблон, логика и стили в одном файле, с областью видимости стилей через `scoped`.

```vue
<script setup>
import { ref } from 'vue';
const name = ref('Vue');
</script>

<template>
  <h1>Привет, {{ name }}</h1>
</template>

<style scoped>
h1 { color: #42b883; }
</style>
```

Три блока: `<script>` (логика), `<template>` (разметка, не JSX, а HTML-подобный синтаксис с директивами), `<style scoped>` (стили только этого компонента). Компилируется Vue-компилятором в обычный JS-компонент.

## Два API: Composition и Options

У Vue 3 два стиля написания компонентов.

```js
// Options API (Vue 2, всё ещё поддерживается)
export default {
  data() { return { count: 0 }; },
  methods: { inc() { this.count++; } },
  computed: { double() { return this.count * 2; } },
};
```

```js
// Composition API (рекомендуется в Vue 3)
import { ref, computed } from 'vue';
const count = ref(0);
const double = computed(() => count.value * 2);
function inc() { count.value++; }
```

<b class="text-on-semi-light">Кратко</b> - <span class="text-gray">Options API раскладывает логику по «опциям» (`data`, `methods`, `computed`). Composition API группирует логику по смыслу и позволяет переиспользовать её через composables. Подробно - в [Composition API](/content/vuejs/composition-api).</span>

## История

| Год | Веха |
|-----|------|
| 2014 | Релиз Vue, Evan You |
| 2016 | Vue 2 - стабильный мажор, экосистема (Vuex, Vue Router) |
| 2020 | **Vue 3** - Composition API, реактивность на Proxy, `<script setup>`, TypeScript |
| 2022 | Vue 3 - версия по умолчанию; Vue 2 → maintenance |
| 2023 | Конец поддержки Vue 2 (EOL, 31.12.2023) |
| 2024–2026 | Развитие: Vapor mode (компиляция без virtual DOM), улучшения реактивности |

Главный сдвиг - **Vue 3 и реактивность на `Proxy`**: она ушла от ограничений Vue 2 (`Object.defineProperty`, который не отслеживал добавление новых свойств и индексы массивов).

## Vue vs React vs Angular

| | Vue | React | Angular |
|--|-----|-------|---------|
| Тип | прогрессивный фреймворк | библиотека (UI) | фреймворк (всё включено) |
| Разметка | шаблоны (SFC) + директивы | JSX | HTML-шаблоны + директивы |
| Реактивность | **тонкая, на Proxy, авто-отслеживание** | ре-рендер + ручная мемоизация | сигналы / Zone.js |
| Официальная экосистема | да (Router, Pinia, Nuxt) | нет (сторонние) | да |

<b class="text-on-semi-light">Главное отличие от React для собеса</b> - <span class="text-gray">React при изменении состояния перерисовывает компонент целиком и диффит результат; оптимизацию (memo/useMemo) ты делаешь руками. Vue отслеживает зависимости на уровне данных и обновляет точечно - мемоизация по большей части не нужна.</span>

## Что входит в экосистему

В отличие от React, у Vue есть **официальные** решения:

- **Vue Router** - роутинг ([роутинг](/content/vuejs/routing)).
- **Pinia** - стейт-менеджмент (заменил Vuex) ([управление состоянием](/content/vuejs/state-management)).
- **Nuxt** - мета-фреймворк: SSR, файловый роутинг, сборка ([рендеринг и Nuxt](/content/vuejs/rendering-and-nuxt)).
- **Vite** - сборщик (создан тем же автором, де-факто стандарт и за пределами Vue).

## Вопросы на собеседовании

<b class="text-on-semi-light">Что значит «прогрессивный фреймворк»?</b>
<span class="text-gray">Vue масштабируется по потребности: от подключения скриптом к странице до полноценного SPA с роутером, стором и SSR. Берёшь столько возможностей, сколько нужно.</span>

<b class="text-on-semi-light">Чем модель Vue отличается от React?</b>
<span class="text-gray">React перерисовывает компонент при смене состояния и диффит, оптимизацию делаешь вручную. Vue отслеживает зависимости данных автоматически и обновляет точечно, без ручной мемоизации.</span>

<b class="text-on-semi-light">Что нового принёс Vue 3?</b>
<span class="text-gray">Composition API, реактивность на Proxy (вместо `Object.defineProperty`), `<script setup>`, полноценный TypeScript, лучшую производительность.</span>

<b class="text-on-semi-light">Чем Options API отличается от Composition API?</b>
<span class="text-gray">Options раскладывает логику по опциям (data/methods/computed). Composition группирует логику по смыслу и переиспользует её через composables. В Vue 3 рекомендуется Composition.</span>

<b class="text-on-semi-light">Что такое SFC?</b>
<span class="text-gray">Single-File Component (`.vue`) - шаблон, логика и scoped-стили в одном файле, компилируемый Vue-компилятором в JS-компонент.</span>
