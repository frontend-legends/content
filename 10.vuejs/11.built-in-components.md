# Встроенные компоненты

Vue даёт несколько встроенных компонентов для задач, которые трудно решить обычным шаблоном: рендер в другое место DOM (`Teleport`), ожидание async-данных (`Suspense`), кэширование переключаемых компонентов (`KeepAlive`) и анимации (`Transition`).

---

## Teleport - рендер в другое место DOM

`<Teleport>` переносит свой контент в **другой узел DOM**, оставляя его при этом логически в дереве компонента. Прямой аналог порталов в React.

```vue
<template>
  <button @click="open = true">Открыть</button>

  <Teleport to="body">
    <div v-if="open" class="modal-overlay">
      <div class="modal">...</div>
    </div>
  </Teleport>
</template>
```

**Зачем:** модалки, тултипы, дропдауны, тосты - элементы, которые должны быть поверх всего и не обрезаться `overflow: hidden` или `z-index`-контекстом родителя. `to` принимает CSS-селектор или элемент.

<b class="text-on-semi-light">Тонкость про дерево</b> - <span class="text-gray">Физически узел уезжает в `body`, но в **дереве компонентов** Teleport остаётся на месте: props, inject, события работают как обычно. То же поведение, что у React-порталов.</span>

## Suspense - ожидание асинхронного

`<Suspense>` показывает запасной контент, пока внутри грузятся **асинхронные зависимости**: компонент с `async setup()` или [async-компонент](#asinhronnye-komponenty).

```vue
<Suspense>
  <template #default>
    <UserProfile />   <!-- внутри async setup() с await -->
  </template>
  <template #fallback>
    <Spinner />       <!-- пока грузится -->
  </template>
</Suspense>
```

```vue
<!-- UserProfile.vue -->
<script setup>
const user = await fetchUser(); // top-level await в setup - компонент «приостанавливается»
</script>
```

Это позволяет писать загрузку данных декларативно, без ручных флагов `isLoading`. Ошибки ловит `onErrorCaptured` родителя или error boundary-обёртка.

> `Suspense` всё ещё помечен как **экспериментальный** - API может меняться. На собесе стоит это упомянуть.

## KeepAlive - кэш переключаемых компонентов

`<KeepAlive>` **сохраняет состояние** компонентов при переключении вместо их уничтожения и пересоздания. Полезно для табов, мастеров, списков с фильтрами.

```vue
<KeepAlive>
  <component :is="currentTab" /> <!-- состояние табов сохраняется при переключении -->
</KeepAlive>
```

Без `KeepAlive` динамический компонент при смене размонтируется и теряет состояние (введённый текст, позицию скролла). С ним - кэшируется.

- `include`/`exclude` - какие компоненты кэшировать, `max` - предел кэша (LRU).
- Хуки `onActivated`/`onDeactivated` - реагировать на показ/скрытие закэшированного компонента.

<b class="text-on-semi-light">Vue vs React</b> - <span class="text-gray">В React встроенного аналога нет - сохранение состояния при размонтировании решают поднятием состояния вверх или библиотеками. `KeepAlive` делает это декларативно.</span>

## Асинхронные компоненты

`defineAsyncComponent` лениво подгружает компонент - основа **code splitting** во Vue.

```js
import { defineAsyncComponent } from 'vue';

const Dashboard = defineAsyncComponent(() => import('./Dashboard.vue'));
```

Расширенная форма с состояниями загрузки/ошибки:

```js
const Comp = defineAsyncComponent({
  loader: () => import('./Heavy.vue'),
  loadingComponent: Spinner,
  errorComponent: ErrorView,
  delay: 200,
  timeout: 5000,
});
```

Async-компоненты работают вместе с `Suspense` и с роутером (ленивые маршруты) - см. [производительность](/content/vuejs/performance).

## Transition и TransitionGroup

Vue даёт **встроенную систему анимаций**. `<Transition>` оборачивает один элемент и навешивает CSS-классы на этапах появления/исчезновения.

```vue
<Transition name="fade">
  <p v-if="show">Привет</p>
</Transition>

<style>
.fade-enter-active, .fade-leave-active { transition: opacity 0.3s; }
.fade-enter-from, .fade-leave-to { opacity: 0; }
</style>
```

Vue автоматически добавляет классы `*-enter-from`, `*-enter-active`, `*-leave-to` и т.д. на нужных фазах. `<TransitionGroup>` - то же для списков (`v-for`), с анимацией перестановки.

> Анимации - в основном практическая тема; здесь важно знать **концепцию**: Vue из коробки даёт классовые хуки на enter/leave, тогда как в React анимации обычно делают библиотеками (Framer Motion).

## Сводка

| Компонент | Задача | React-аналог |
|-----------|--------|--------------|
| `Teleport` | рендер в другое место DOM | `createPortal` |
| `Suspense` | ожидание async-зависимостей | `<Suspense>` |
| `KeepAlive` | кэш состояния переключаемых компонентов | нет встроенного |
| `defineAsyncComponent` | ленивая загрузка | `React.lazy` |
| `Transition` | анимации enter/leave | сторонние библиотеки |

## Вопросы на собеседовании

<b class="text-on-semi-light">Что делает Teleport и зачем он нужен?</b>
<span class="text-gray">Переносит контент в другой узел DOM (обычно body), оставляя его в дереве компонента. Для модалок/тултипов, чтобы не обрезались overflow и z-index. Аналог порталов React.</span>

<b class="text-on-semi-light">Для чего Suspense во Vue?</b>
<span class="text-gray">Показать fallback, пока грузятся async-зависимости (async setup, async-компоненты), без ручных флагов загрузки. Пока экспериментальный.</span>

<b class="text-on-semi-light">Что делает KeepAlive?</b>
<span class="text-gray">Кэширует переключаемые/динамические компоненты, сохраняя их состояние вместо уничтожения. Хуки onActivated/onDeactivated, опции include/exclude/max.</span>

<b class="text-on-semi-light">Как сделать ленивую загрузку компонента?</b>
<span class="text-gray">`defineAsyncComponent(() => import('...'))` - основа code splitting, работает с Suspense и роутером.</span>

<b class="text-on-semi-light">Как Vue анимирует появление/исчезновение?</b>
<span class="text-gray">Через `<Transition>`: автоматически навешивает CSS-классы на фазах enter/leave. `<TransitionGroup>` - для списков с анимацией перестановки.</span>
