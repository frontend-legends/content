# React

React — библиотека, которая превращает функцию от состояния в интерфейс и сама приводит DOM к нужному виду. На собеседованиях React разбирают глубже любой другой технологии фронтенда. Спрашивают не про синтаксис, а про модель: почему компонент перерендерился, где лежит состояние хука, что сломается без `key` и что из Server Components попадёт в браузер.

## Что спрашивают

- **На mid** — правила хуков и stale closure, `key` в списках, управляемые поля, когда нужен `useEffect`, а когда нет, контекст против стора.
- **На mid+** — почему компонент рендерится вместе с родителем, `memo` и `useCallback`, водопады запросов, гидратация и её расхождения.
- **На senior** — механика хуков на fiber, очередь `setState` и приоритеты, сравнение списков в reconciliation, tearing и `useSyncExternalStore`.
- **Там же на senior** — граница Server Components и сериализация, безопасность серверных функций, стратегия тестов.
